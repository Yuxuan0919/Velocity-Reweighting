\begin{abstract}
Large language model with reinforcement learning
usually learns a reward-tilted conditional distribution,
in a parametric form.
In diffusion model,
the distribution for the clean data 
is non-parametric, and
represented by samples,
and the diffusion model learns a denoising process
to approximate the distribution.
Inspired by this,
we decompose the problem into two steps.
reweight the samples according to rewards,
and update the flow matching with weighted samples
in an incremental way.
The reweighting scheme is a non-parametric way for the reward-tilted distribution,
formulated
from KL-constrained reward maximization. 
The incremental update consists of the target velocity 
estimation from the original velocity
and velocity correction that depends on  mass shift 
and timestep-dependent contribution weight,
followed by an MSE loss for velocity update.
We also note that
several existing methods
can also be casted into 
sampling reweighting and 
velocity correction.


\end{abstract}

\subsection{Reward-Tilted Sample Reweighting}
\noindent\textbf{KL-constrained reward maximization.}
We first consider a KL-constrained reward maximization objective, which
updates the generative distribution toward high-reward regions while
preserving proximity to the original distribution. Given an old distribution
$\pi_{\mathrm{old}}(\mathbf{z})$
and the reward $r(\mathbf{z})$, we solve
\begin{align}
\max_{\pi}
\quad
\mathbb{E}_{\mathbf{z}\sim\pi}
[r(\mathbf{z})]
-
\gamma
D_{\mathrm{KL}}
(\pi(\mathbf{z})\|
\pi^{\mathrm{o}}(\mathbf{z})).
\end{align}
The optimal solution can be obtained by exponential tilting:
\begin{align}
\pi^{\mathrm{n}}(\mathbf{z})
=
\frac{1}{Z}
\pi^o(\mathbf{z})
\exp
\left(
\frac{r(\mathbf{z})}{\gamma}
\right),\label{eqn:exponentialtilting}
\end{align}
where $Z$ is the normalization constant. Therefore, the KL-constrained reward optimization
can be interpreted as reweighting the original distribution according to the
exponential reward preference.

\noindent\textbf{Sample reweighting.}
We transform the 
reward-tilted distribution
from the parametric form
to the non-parametric form.
We denote $\mathbf{z}$,
a sample drawn from
the old distribution.
Its reward-induced unnormalized weight is
$\exp
\left(
\frac{r(\mathbf z)}{\gamma}
\right)$.
The normalization constant is 
\begin{align}
Z = \mathbb{E}_{\mathbf{z} \sim \pi^o}\left[\exp
\left(
\frac{r(\mathbf z)}{\gamma}
\right)\right].
\end{align}
Thus,
the normalized weight becomes
\begin{align}
w(\mathbf z) =
\frac{1}{Z}
\exp
\left(
\frac{r(\mathbf z)}{\gamma}
\right)
=
\frac{
\exp(r(\mathbf z)/\gamma)
}
{
\frac{1}{D}
\sum_j
\exp(r(\mathbf z_j)/\gamma)
}.    
\end{align}

In summary,
the reward-tilted distribution 
is represented
by reweighted rollout samples:
$\{(\mathbf{z}, w(\mathbf{z})\}$

\subsection{Incremental Velocity Target Update}
\noindent\textbf{Optimal velocity field.} 
We first give the optimal velocity field in standard flow matching. 
It is the posterior expectation of the conditional velocity:
\begin{align}
\mathbf{v}(\mathbf{x}_t,t)
=
\mathbb{E}_{\mathbf{z} | \mathbf{x}_t}
\left[
\mathbf{v}_t(\mathbf{x}_t|\mathbf{z})
\mid
\mathbf{x}_t
\right].
\end{align}
The distribution is
\begin{align}
p(\mathbf{z}|\mathbf{x}_t)
=
\frac{
\pi(\mathbf{z})
p_t(\mathbf{x}_t|\mathbf{z})
}
{
\int
\pi(\mathbf{z}')
p_t(\mathbf{x}_t|\mathbf{z}')
d\mathbf{z}'
} 
= 
\frac{
\pi(\mathbf{z})
p_t(\mathbf{x}_t|\mathbf{z})
}
{
p_t(\mathbf{x}_t)
},
\end{align}
where
$
p_t(\mathbf{x}_t)$
denotes the marginal distribution.
The optimal velocity field becomes
\begin{align}
\mathbf{v}(\mathbf{x}_t,t)
&= 
\mathbb{E}_{\mathbf{z}\sim\pi}
\left[
\frac{p_t(\mathbf{x}_t|\mathbf{z})}
{
p_t(\mathbf{x}_t)
}
\mathbf{v}_t(\mathbf{x}_t|\mathbf{z})
\right]
\\
&=
\mathbb{E}_{\mathbf{z}\sim\pi}
[
\alpha_t(\mathbf{x}_t,\mathbf{z})
\mathbf{v}_t(\mathbf{x}_t|\mathbf{z})
]\\
&=
\sum_{k=1}^K
\frac{1}{K}
\alpha_t(\mathbf{x}_t,\mathbf{z}_k)
\mathbf{v}_t(\mathbf{x}_t|\mathbf{z}_k)
.
\end{align}
Here, $\alpha_t(\mathbf{x}_t,\mathbf{z})
=
\frac{
p_t(\mathbf{x}_t|\mathbf{z})
}
{
p_t(\mathbf{x}_t)
}$ (conditional-to-marginal ratio) 
serves as a posterior correction
factor that transforms the prior distribution $\pi(\mathbf{z})$ into the
conditional distribution $p(\mathbf{z}|\mathbf{x}_t)$.


\noindent\textbf{Velocity field
from
unweighted to reweighted samples.} 
The optimal velocity field 
for reweighted samples
is given as the following,
\begin{align}
    \mathbf{v}^{n}(\mathbf{x}_t,t)
    &=  \frac{1}{\sum_{k=1}^Kw(\mathbf{z}_k)}
    \sum_{k=1}^K
    w(\mathbf{z}_k)
\alpha^n_t(\mathbf{x}_t,\mathbf{z}_k)
\mathbf{v}_t(\mathbf{x}_t|\mathbf{z}_k) \\
&\approx  \frac{1}{\sum_{k=1}^Kw(\mathbf{z}_k)}
\sum_{k=1}^K
    w(\mathbf{z}_k)
\alpha^o_t(\mathbf{x}_t,\mathbf{z}_k)
\mathbf{v}_t(\mathbf{x}_t|\mathbf{z}_k) \\
&=  \frac{1}{K + \sum_{k=1}^K(w(\mathbf{z}_k) - 1)}
(
\sum_{k=1}^K
\alpha^o_t(\mathbf{x}_t,\mathbf{z}_k)
\mathbf{v}_t(\mathbf{x}_t|\mathbf{z}_k) 
+ 
\sum_{k=1}^K
    ( w(\mathbf{z}_k) - 1)
\alpha^o_t(\mathbf{x}_t,\mathbf{z}_k)
\mathbf{v}_t(\mathbf{x}_t|\mathbf{z}_k)
)\\
&=  \mathbf{v}^o(\mathbf{x}_t,t)
+ \frac{1}{K + \sum_{k=1}^K
    ( w(\mathbf{z}_k) - 1)} 
\sum_{k=1}^K
    ( w(\mathbf{z}_k) - 1)
    (
\alpha^o_t(\mathbf{x}_t,\mathbf{z}_k)
\mathbf{v}_t(\mathbf{x}_t|\mathbf{z}_k)
- \mathbf{v}^o(\mathbf{x}_t,t)
)\\
&=  \mathbf{v}^o(\mathbf{x}_t,t)
+ \frac{1}{K} 
\sum_{k=1}^K
    ( w(\mathbf{z}_k) - 1)
\alpha^o_t(\mathbf{x}_t,\mathbf{z}_k)
(
\mathbf{v}_t(\mathbf{x}_t|\mathbf{z}_k)
- \frac{1}{\alpha^o_t(\mathbf{x}_t,\mathbf{z}_k)}\mathbf{v}^o(\mathbf{x}_t,t)
)
.
\end{align}
Here,
the approximation
from the first line to the second line
is that 
we use $\alpha^o$
to approximate $\alpha^n$.
The last equality
is based on the incremental update,
whose details are given in 
Appendix.

\noindent\textbf{Online ratio $\alpha^o_t(\mathbf{x}_t,\mathbf{z}_k)$.}
The conditional-to-marginal ratio
$\alpha_t(\mathbf{x}_t,\mathbf{z})
=
\frac{
p_t(\mathbf{x}_t|\mathbf{z})
}
{
p_t(\mathbf{x}_t)
}$ 
is computationally infeasible.
The numerator 
$p_t(\mathbf{x}_t|\mathbf{z})$
can be computed,
and the dominator
$
p_t(\mathbf{x}_t)
= \mathbb{E}_{\mathbf{z}} [p_t(\mathbf{x}_t|\mathbf{z})]
$
is not easy to compute
{as we need to enumerate
many $\mathbf{z}$
for the same $\mathbf{x}_t$}.

We find that
$\alpha_t(\mathbf{x}_t,\mathbf{z})$
reflects
the degree
that 
$\mathbf{z}$ contributes to $\mathbf{x}_t$.
The contribution degree
is monotonically related to 
the distance between 
the velocity $\mathbf{v}(\mathbf{x}_t,t)$ and 
$\mathbf{v}_t(\mathbf{x}_t | \mathbf{z})$:
$
\|
\mathbf{v}_t(\mathbf{x}_t | \mathbf{z})
- \mathbf{v}(\mathbf{x}_t,t)\|_1
$.
In addition,
we notice that 
the expectation of 
$\alpha_t(\mathbf{x}_t,\mathbf{z})
\propto \tilde{\alpha}_t(\mathbf{x}_t,\mathbf{z})
=
\frac{1}
{
\|
\mathbf{v}_t(\mathbf{x}_t | \mathbf{z})
- \mathbf{v}(\mathbf{x}_t,t)\|_1}
$
is $1$.
So we perform batch normalization
as the approximation:
\begin{align}
    \alpha_t(\mathbf{x}_t,\mathbf{z})
    = \frac{\tilde{\alpha}_t(\mathbf{x}_t,\mathbf{z})}
    {
    \frac{1}{B}
    \sum_b \tilde{\alpha}_{t_b}(\mathbf{x}_{t_b},\mathbf{z}_b)
    }
\end{align}

online velocity model, 
which makes the learning process instable.
We follow the widely-used strategy
and use EMA velocity $\mathbf{v}^{-}(\mathbf{x}_t,t)$ to
replace 
$\mathbf{v}^o(\mathbf{x}_t,t)$
form the target:
\begin{align}
    \boldsymbol{\theta}^{-}_t
    = \rho \boldsymbol{\theta}^{-}_t
    + (1-\rho) \boldsymbol{\theta}_t.
\end{align}

In addition,
the coefficient 
$\frac{1}{\alpha^o_t(\mathbf{x}_t,\mathbf{z}_k)}$ of
the second $\mathbf{v}^o(\mathbf{x}_t,t)$
also changes online,
making the learning process instable.
We considered two options.
The first option
is to use an EMA ratio.
The second one is
to use the expectation 
of the ratio:
$\mathbb{E}_{\mathbf{z}}[\alpha^o_t(\mathbf{x}_t,\mathbf{z})] = 1$.

\subsection{Strict Derivation of Reward-Tilted Velocity Correction}
\label{sec:strict_correction}


Using the importance weight, we rewrite $\mathbf{v}^{\mathrm{n}}$ as an
expectation under $\pi^{\mathrm{o}}$:
\begin{align}
\mathbf{v}^{\mathrm{n}}(\mathbf{x}_t,t)
=
\mathbb{E}_{\mathbf{z}\sim\pi^{\mathrm{o}}}
\left[
w_r(\mathbf{z})\,
\alpha_t^{\mathrm{n}}(\mathbf{x}_t,\mathbf{z})\,
\mathbf{v}_t(\mathbf{x}_t|\mathbf{z})
\right].
\end{align}
The exact increment is therefore
\begin{align}
\Delta(\mathbf{x}_t,t)
&=
\mathbf{v}^{\mathrm{n}}(\mathbf{x}_t,t)
-
\mathbf{v}^{\mathrm{o}}(\mathbf{x}_t,t)
\\
&=
\mathbb{E}_{\pi^{\mathrm{o}}}
\left[
\left(
w_r\alpha_t^{\mathrm{n}}
-
\alpha_t^{\mathrm{o}}
\right)
\mathbf{v}_t
\right]
\\
&=
\mathbb{E}_{\pi^{\mathrm{o}}}
\left[
(w_r-1)\alpha_t^{\mathrm{o}}\,
\mathbf{v}_t
\right]
+
\mathbb{E}_{\pi^{\mathrm{o}}}
\left[
w_r(\alpha_t^{\mathrm{n}}-\alpha_t^{\mathrm{o}})\,
\mathbf{v}_t
\right].
\end{align}


To obtain a computable form, we adopt the approximation
\begin{align}
\alpha_t^{\mathrm{n}}(\mathbf{x}_t,\mathbf{z})
\approx
\alpha_t^{\mathrm{o}}(\mathbf{x}_t,\mathbf{z}).
\end{align}
Under this approximation,
\begin{align}
\Delta(\mathbf{x}_t,t)
&\approx
\mathbb{E}_{\pi^{\mathrm{o}}}
\left[
(w_r-1)\alpha_t^{\mathrm{o}}\,
\mathbf{v}_t(\mathbf{x}_t|\mathbf{z})
\right].
\end{align}

Since $\mathbb{E}_{\pi^{\mathrm{o}}}[\alpha_t^{\mathrm{o}}]=1$,
the increment can be decomposed as
\begin{align}
\Delta(\mathbf{x}_t,t)
&\approx
\mathbb{E}_{\pi^{\mathrm{o}}}
\left[
(w_r-1)\alpha_t^{\mathrm{o}}\,
\left(
\mathbf{v}_t-\mathbf{v}^{\mathrm{o}}
\right)
\right]
+
\mathbf{v}^{\mathrm{o}}\,
\mathbb{E}_{\pi^{\mathrm{o}}}
\left[
(w_r-1)\alpha_t^{\mathrm{o}}
\right].
\end{align}

Under the incremental update regime, we assume that the reward-induced
distribution shift is sufficiently small such that the timestep marginal
distribution changes only mildly,
$p_t^{\mathrm{n}}(\mathbf{x}_t)
\approx
p_t^{\mathrm{o}}(\mathbf{x}_t)$.
Since
\begin{align}
\mathbb{E}_{\pi^{\mathrm{o}}}
\left[
w_r\alpha_t^{\mathrm{o}}
\right]
=
\frac{
p_t^{\mathrm{n}}(\mathbf{x}_t)
}{
p_t^{\mathrm{o}}(\mathbf{x}_t)
},
\end{align}
and
$\mathbb{E}_{\pi^{\mathrm{o}}}
[\alpha_t^{\mathrm{o}}]=1$,
we have
\begin{align}
\mathbb{E}_{\pi^{\mathrm{o}}}
\left[
(w_r-1)\alpha_t^{\mathrm{o}}
\right]
=
\frac{
p_t^{\mathrm{n}}(\mathbf{x}_t)
}{
p_t^{\mathrm{o}}(\mathbf{x}_t)
}
-1
\approx
0.
\end{align}


the global offset vanishes and the increment becomes a pure local
correction:
\begin{align}
\Delta(\mathbf{x}_t,t)
&\approx
\mathbb{E}_{\pi^{\mathrm{o}}}
\left[
(w_r-1)\alpha_t^{\mathrm{o}}\,
\left(
\mathbf{v}_t(\mathbf{x}_t|\mathbf{z})
-
\mathbf{v}^{\mathrm{o}}(\mathbf{x}_t,t)
\right)
\right].
\end{align}

\subsection{Implementation}
\noindent\textbf{Monte Carlo form.}
The reward-tilted velocity field can be viewed as a correction of the
original velocity field $\mathbf v_{\mathrm{old}}(\mathbf x_t,t)$.
Instead of explicitly modifying the sampling dynamics, we learn a new
velocity estimator by matching the model prediction to the reward-induced
target velocity. Specifically, the correction term is 
\begin{align}
\mathbf v^n(\mathbf x_t,t)
=
\mathbf v^{\mathrm{o}}(\mathbf x_t,t)
+ 
\mathbf c_t(\mathbf x_t,\mathbf z),
\end{align}
where $\mathbf c_t(\mathbf x_t,\mathbf z)$ represents the reward-induced
velocity correction and $\beta/\bar Z$ controls its magnitude. Therefore,
the updated velocity field can be obtained by minimizing the following
regression objective:
\begin{align}
\min_{\theta}
\mathbb{E}_{t, \mathbf z\sim\pi^{\mathrm{o}}(\mathbf z),\mathbf x_t\sim p_t(\cdot|\mathbf z)}
\left[
w_{\mathcal D}(\mathbf z)
\left\|
\mathbf v_{\boldsymbol{\theta}}(\mathbf x_t,t)
-
\mathtt{sg}(
\mathbf v^{\mathrm{o}}(\mathbf x_t,t)
+ 
\mathbf c_t(\mathbf x_t,\mathbf z))
\right\|_2^2
\right].
\end{align}

This objective encourages the new velocity field to preserve the original
generative dynamics while incorporating the reward-induced correction.
Compared with direct reward-guided sampling, the reward signal is absorbed
into the learned vector field, enabling efficient sampling without
evaluating the reward model during inference.


\noindent\textbf{On-policy or one-step gradient descent.}
The gradient is as follows,
\begin{align}
~&-2 w_{\mathcal D}(\mathbf z)
\frac{\partial\mathbf{v}_{\boldsymbol{\theta}}(\mathbf x_t,t)}
{\partial \boldsymbol{\theta}}
\mathbf c_t(\mathbf x_t,\mathbf z)) \\
 =~& 
 -2\underbrace{
 \frac{\pi^n(\mathbf z)}
 {\pi^{\mathrm{o}}(\mathbf z)}
 }_{\text{importance weight}}
 \times
 \underbrace{
 \alpha^o_t(\mathbf x_t,\mathbf z)
 }_{\text{trajectory contribution}}
 \times
 \underbrace{
\beta
\left(
\frac{\exp\!\left(r(\mathbf{z})/\gamma\right)}{Z}
-
1
\right)
 }_{\text{mass shift}}
 \times
 \underbrace{\frac{\partial\mathbf{v}_{\boldsymbol{\theta}}(\mathbf x_t,t)}
 {\partial \boldsymbol{\theta}}}_{\text{Jacobian}}
 \times
 \underbrace{
 \left(
 \mathbf v_t(\mathbf x_t|\mathbf z)
 -
 \mathbf v_{\boldsymbol{\theta}}(\mathbf x_t,t)
 \right)
 }_{\text{velocity discrepancy}}.
\end{align}

The last two terms on the right-hand side correspond to the standard flow matching
gradient, where the velocity discrepancy provides the regression direction and the
Jacobian term propagates this discrepancy to the model parameters.


The proposed formulation equivalently introduces an adaptive weighting mechanism on top of the
standard flow matching objective.
The overall update can be viewed as an adaptive flow matching update,
where the effective learning signal is modulated by the adaptive factor
\begin{align}
w_{\mathrm{adapt}}(\mathbf x_t,\mathbf z)
=
\frac{\pi^n(\mathbf z)}
{\pi^{\mathrm{o}}(\mathbf z)}
\alpha_t^o(\mathbf x_t,\mathbf z)
\beta
\left(
\frac{\exp\!\left(r(\mathbf{z})/\gamma\right)}{Z}
-
1
\right).
\end{align}
Compared with conventional flow matching, which treats all training pairs equally,
the proposed weighting dynamically emphasizes samples that are more aligned with
the optimal policy, have higher contribution to the transport trajectory, and
receive higher reward.



\noindent\textbf{\color{red}Trajectory contribution weight.}
Although the exact trajectory contribution weight
\begin{align}
\alpha_t(\mathbf{x}_t,\mathbf z)
=
\frac{
p_t(\mathbf{x}_t|\mathbf z)
}
{
p_t(\mathbf{x}_t)
}
\end{align}
is theoretically well-defined, directly estimating this density ratio is
challenging since the marginal
density may be intractable. 

Instead, we exploit the posterior averaging property of the optimal velocity
field:
\begin{align}
\mathbf v(\mathbf{x}_t,t)
=
\mathbb{E}_{\mathbf z\sim\pi}
\left[
\alpha_t(\mathbf{x}_t,\mathbf z)
\mathbf v_t(\mathbf{x}_t|\mathbf z)
\right].
\end{align}
A trajectory
with a larger posterior contribution
$\pi(\mathbf{z})\alpha_t(\mathbf{x}_t,\mathbf z)$ is expected to have a conditional velocity
that is more consistent with the optimal velocity field
$\mathbf v(\mathbf{x}_t,t)$. Therefore, for sample $i$ in the current training
group $\mathcal G$, we measure its velocity discrepancy by the mean absolute
error over all non-batch dimensions:
\begin{align}
d_{t,i}
=
\operatorname{mean}_{\mathrm{feat}}
\left|
\mathbf v_i-
\mathbf v_i^{\mathrm{old}}
\right|,
\end{align}
where $\mathbf v_i$ is the conditional target velocity and
$\mathbf v_i^{\mathrm{old}}$ is the old-model velocity prediction. We first form
the unnormalized reciprocal-discrepancy score
\begin{align}
\tilde{\alpha}_{t,i}
=
\frac{1}{d_{t,i}+\epsilon_{\mathrm{alg}}}.
\end{align}
We then normalize these scores within the current training group:
\begin{align}
\alpha_{t,i}^{\mathcal G}
&=
\frac{
\tilde{\alpha}_{t,i}
}{
|\mathcal G|^{-1}
\sum_{j\in\mathcal G}\tilde{\alpha}_{t,j}
},
&
\frac{1}{|\mathcal G|}
\sum_{i\in\mathcal G}\alpha_{t,i}^{\mathcal G}
&=1.
\end{align}
In the implementation, $\mathcal G$ is the current per-device training
minibatch at a fixed training timestep. Both the reciprocal score and its
group mean are computed with stopped gradients. This empirical unit-mean
constraint matches the theoretical identity
$\mathbb{E}_{\mathbf z}[\alpha_t(\mathbf{x}_t,\mathbf z)]=1$, while preserving
the relative trajectory contributions inside each group and preventing their
overall scale from changing the correction magnitude across minibatches.

{\color{red}
The intuition is that the velocity discrepancy is jointly determined by the
trajectory contribution factor $\alpha_t(\mathbf{x}_t,\mathbf z)$ and the source
probability $\pi(\mathbf z)$. Since $\mathbf z$ is sampled from $\pi(\mathbf z)$,
the sampled trajectories typically have non-negligible probability mass.
Therefore, variations in the velocity discrepancy mainly reflect the relative
contribution factor $\alpha_t(\mathbf{x}_t,\mathbf z)$. In particular, a small
velocity discrepancy indicates that the trajectory is more consistent with the
optimal velocity field and is likely associated with a larger contribution
factor, whereas a large velocity discrepancy suggests a smaller contribution
factor. The group normalization retains this relative ordering but calibrates
the average factor to one within every training group.
}

{\color{red}
Note that this does not provide an exact estimation of
$\alpha_t(\mathbf{x}_t,\mathbf z)$, since the velocity field depends on the
posterior contribution $\pi(\mathbf z)\alpha_t(\mathbf{x}_t,\mathbf z)$.
Instead, $\alpha_{t,i}^{\mathcal G}$ serves as a tractable, group-normalized
surrogate for the relative contribution among sampled trajectories.
}

    \|_2^2
    }
    {
    \texttt{sg}(\texttt{mean}
    (\texttt{abs}(
    \mathbf{v}(\mathbf{x}_t,t) - \mathbf{v}
    )
    ))
    }
\end{align}
}




\noindent\textbf{Importance weights.}
We need to compute unnormalized importance weight, $\bar{w}(\mathbf{z}) = \exp(r(\mathbf z)/\gamma)$, 
for reward-guided mass shift.

\emph{GRPO-style:} 
At each training iteration, let $R_{j,k}$ be the reward of rollout $k$
for prompt $c_j$, where $j=1,\ldots,C$, $k=1,\ldots,K$, and
$D=CK$. We center rewards by the mean of their prompt group,
\begin{align}
\bar R_{c_j}
=
\frac{1}{K}\sum_{k=1}^{K}R_{j,k},
\end{align}
and use the population standard deviation over all rollout rewards in the
current iteration as the common reward scale:
\begin{align}
\bar R
&=
\frac{1}{D}\sum_{j=1}^{C}\sum_{k=1}^{K}R_{j,k},\\
\sigma_R
&=
\sqrt{
\frac{1}{D}\sum_{j=1}^{C}\sum_{k=1}^{K}
(R_{j,k}-\bar R)^2
}
+\epsilon_R.
\end{align}
Given the mass-shift clip $\Delta_{\mathrm{clip}}>0$, the signed mass shift
and unnormalized importance weight are
\begin{align}
\Delta_{j,k}
&=
\frac{1}{\Delta_{\mathrm{clip}}}
\operatorname{clip}
\left(
\frac{R_{j,k}-\bar R_{c_j}}{\sigma_R},
-\Delta_{\mathrm{clip}},
\Delta_{\mathrm{clip}}
\right),\\
W_{j,k}&=1+\Delta_{j,k}.
\end{align}
Thus, rewards are centered within each prompt group but share a global scale
computed from the current rollout iteration. For asymmetric mass shifts, we
use $\sigma_+=c\sigma_R$ and $\sigma_-=\sigma_R/c$, as detailed in the
ablation study.



One similar choice is derived 
by miximizing
\begin{align}
    \sum_i r_i w_i
\end{align}
with the constraint $\sum_i w^2_i = c$:
then $w_i = \frac{r_i}{\frac{1}{N}\sum_{j} r_j}
= \frac{r_i}{\beta + \beta/D \sum_l r_j}$. 
$r_j$ (regarded as $\bar{w}(\mathbf{z}) = \exp(r(\mathbf{z})/\gamma)$) is normalized so that
the reward of background sample is $1$,
larger than $1$ is good,
smaller than $1$ is bad,
of course it could also be clipped.

\emph{$\mathtt{Softmax}$-style:}
$r$ is adjusted so that $r=0$
for the background sample.
\begin{align}
    \bar{w}(\mathbf{z}) = \frac{\exp(r/t))}
    {\beta + \beta/D\sum_{i=1}^D\exp(r_i/t)}
\end{align}
$t$ plays a role,
something like the $\mathtt{clip}$ operator,
transforming $r$ to a probability.
If $t=0$, it becomes $\mathtt{max}$
If $t=\infty$,
it becomes uniform, all are $1$.

\begin{algorithm}[H]
    \caption{Reinforced Flow Matching}
    \label{alg:velocity-add-delete}
    \textbf{Require:} Initial model $\theta_0$, reward function $R$, prompt distribution $p(c)$, number of prompts per iteration $C$, rollout size per prompt $K$, batch size $B$, total samples per iteration $D = KC$, rollout coverage coefficient $\beta$, mass-shift clip $\Delta_{\mathrm{clip}}$, reference regularization $\lambda_{\mathrm{ref}}$, EMA rate $\eta$, reward-scale constant $\epsilon_R$, numerical constant $\epsilon_{\mathrm{alg}}$, gradient accumulation steps $N_{\mathrm{acc}}$.\\
    \textbf{Initialize:} Training policy $\theta \leftarrow \theta_0$, old policy $\theta_{\mathrm{old}} \leftarrow \theta_0$, reference policy $\theta_{\mathrm{ref}} \leftarrow \theta_0$, data buffer $\mathcal{D} \leftarrow \emptyset$.
    \begin{algorithmic}[1]
        \For{\text{each iteration}}
            \For{\text{each prompt $c_j \sim p(c)$, $j = 1, \dots, C$}} \Comment{Rollout Step, Data Collection}
                \State Sample $K$ clean images $\{\mathbf{x}_0^{j,k}\}_{k=1}^{K}$ with $\theta$ conditioned on $c_j$.
                \State Evaluate rewards $R_{j,k} \leftarrow R(\mathbf{x}_0^{j,k}, c_j)$ for $k = 1, \dots, K$.
            \EndFor

            \State Compute prompt-wise reward means
            $\bar{R}_{c_j} \leftarrow \frac{1}{K}\sum_{k=1}^{K} R_{j,k}$ for $j = 1, \dots, C$.

            \State Compute global reward mean
            $\bar{R} \leftarrow \frac{1}{D}\sum_{j=1}^{C}\sum_{k=1}^{K} R_{j,k}$.

            \State Compute global reward scale
            $\sigma_R \leftarrow \sqrt{\frac{1}{D}\sum_{j=1}^{C}\sum_{k=1}^{K}(R_{j,k} - \bar{R})^2} + \epsilon_R$.

            \For{\text{each prompt $c_j$, $j = 1, \dots, C$}}
                \State Compute normalized weights
                \[
                    \Delta_{j,k} \leftarrow \frac{1}{\Delta_{\mathrm{clip}}}
                    \operatorname{clip}\!\left(
                        \frac{R_{j,k} - \bar{R}_{c_j}}{\sigma_R},
                        -\Delta_{\mathrm{clip}},
                        \Delta_{\mathrm{clip}}
                    \right),
                    \quad
                    W_{j,k} \leftarrow 1 + \Delta_{j,k},
                    \quad k = 1, \dots, K.
                \]
                \State $\bar{Z}_{c_j} \leftarrow 1 + \frac{\beta}{K}\sum_{k=1}^{K}\Delta_{j,k}$.
                \State Store samples in buffer:
                $\mathcal{D} \leftarrow \mathcal{D} \cup \{(c_j, \mathbf{x}_0^{j,k}, W_{j,k}, \bar{Z}_{c_j})\}_{k=1}^{K}$.
            \EndFor

            \For{\text{each mini batch } $\{(c_i, \mathbf{x}_i^0, W_i, \bar{Z}_{c_i})\}_{i=1}^{B} \subset \mathcal{D}$} \Comment{Gradient Step, Policy Optimization}
                \State Sample timesteps $t_i \sim \mathcal{U}(0,1)$ and noise $\boldsymbol{\epsilon}_i \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$.
                \State Set $\mathbf{x}_i^{t_i} \leftarrow (1 - t_i)\mathbf{x}_i^0 + t_i\boldsymbol{\epsilon}_i$ for $i = 1, \dots, B$.
                \State Ground-truth velocity: $\mathbf{v}_i \leftarrow \boldsymbol{\epsilon}_i - \mathbf{x}_i^0$.
                \State Predicted velocities:
                $\mathbf{v}_i^{\theta} \leftarrow \mathbf{v}_{\theta}(\mathbf{x}_i^{t_i}, c_i, t_i)$,
                $\mathbf{v}_i^{\mathrm{old}} \leftarrow \mathbf{v}_{\theta_{\mathrm{old}}}(\mathbf{x}_i^{t_i}, c_i, t_i)$,
                $\mathbf{v}_i^{\mathrm{ref}} \leftarrow \mathbf{v}_{\theta_{\mathrm{ref}}}(\mathbf{x}_i^{t_i}, c_i, t_i)$.

                \State Compute per-sample scale:
                \[
                    \widetilde{\alpha}_i \leftarrow
                    \frac{1}{
                        \operatorname{sg}\!\left[
                            \operatorname{mean}\left|\mathbf{v}_i - \mathbf{v}_i^{\theta}\right|
                        \right] + \epsilon_{\mathrm{alg}}
                    },
                    \quad
                    \alpha_i \leftarrow
                    \frac{\widetilde{\alpha}_i}{
                        \frac{1}{B}\sum_{j=1}^{B}\widetilde{\alpha}_j
                    },
                    \quad i = 1, \dots, B.
                \]

                \State Target velocity:
                \[
                    \mathbf{v}_i^{\mathrm{target}} \leftarrow
                    \mathbf{v}_i^{\mathrm{old}}
                    +
                    \beta\left(
                        \frac{W_i}{\bar{Z}_{c_i}} - 1
                    \right)
                    \alpha_i\left(
                        \mathbf{v}_i - \mathbf{v}_i^{\mathrm{old}}
                    \right).
                \]

                \State $\mathcal{L}_{\mathrm{target}} \leftarrow
                \frac{1}{B}\sum_{i=1}^{B} t_i
                \left\|\mathbf{v}_i^{\theta} - \mathbf{v}_i^{\mathrm{target}}\right\|_2^2$.

                \State $\mathcal{L}_{\mathrm{ref}} \leftarrow
                \frac{1}{B}\sum_{i=1}^{B}
                \left\|\mathbf{v}_i^{\theta} - \mathbf{v}_i^{\mathrm{ref}}\right\|_2^2$.

                \State $\mathcal{L} \leftarrow
                \frac{1}{N_{\mathrm{acc}}}\left(
                    \Delta_{\mathrm{clip}}\mathcal{L}_{\mathrm{target}}
                    +
                    \lambda_{\mathrm{ref}}\mathcal{L}_{\mathrm{ref}}
                \right)$.

                \State Backpropagate $\mathcal{L}$ and accumulate gradients without updating $\theta$.
            \EndFor

            \State Update $\theta$ once using the accumulated gradients.
            \State $\theta_{\mathrm{old}} \leftarrow \eta\theta_{\mathrm{old}} + (1-\eta)\theta$, clear buffer $\mathcal{D} \leftarrow \emptyset$. \Comment{Online Update}
        \EndFor
    \end{algorithmic}
    \textbf{Output:} $\mathbf{v}_\theta$
\end{algorithm}

$\Delta_{j,k}$ as the base scheme.  Scheme B selects strong-tail samples on
both sides, whereas Scheme C keeps all negative samples and selects only the
positive strong tail.

The selected mass is approximately a fraction $\rho$ of the corresponding
base mass.  Dividing the retained signal by $\rho$ therefore approximately
preserves the total mass while reallocating it from
borderline samples to strong signal samples.  In Scheme C, the negative side is not
selected and is consequently not divided by $\rho$.

When $\rho=1$, no sample is removed and both schemes reduce exactly to the base scheme under the
same training hyperparameters.  When $\rho<1$, the
total mass is approximately preserved because the selection boundary
must fall between discrete samples.  Thus these schemes mainly test the
effect of concentrating the base training signal on stronger samples.

\paragraph{Baseline equivalence check.}
The run with $\rho=1$ and $\beta=1$ verifies that the selection
implementation reduces to the base scheme: no sample is discarded, hence
$w_{j,k}-1=\Delta_{j,k}$.  The expected result is that its learning curve and final metrics match the base scheme.

\paragraph{Scheme B: symmetric selection.}
 Comparisons between different $\rho$ at fixed $\beta$ test whether
concentrating both positive and negative signals on strong-tail samples is
better than retaining borderline samples; comparisons between different $\beta$ at fixed $\rho$ test
the required target-shift magnitude.  The intended conclusion is whether a
moderate $\rho$ and a compatible $\beta$ improve convergence or
stability over the base scheme, and whether aggressive selection must be
paired with a smaller $\beta$.

\paragraph{Scheme C: asymmetric selection.}
Comparing B and C at the same $(\rho,\beta)$ isolates this asymmetry.  Better and equally stable results from C would support keeping all negative samples and filtering only borderline positive samples; better results from B would favor symmetric selection, while a best result at $\rho=1$ would indicate no benefit from hard selection.

\section{Experiments}
\label{sec:experiments}

\subsection{Experimental setup}
\label{sec: exp-setting}
We follow the experimental setup used by DiffusionNFT~\citep{zheng2026diffusionnft}. Unless otherwise specified, all experiments start from SD3.5-Medium~\citep{esser2024scaling} at $512 \times 512$ resolution.

\paragraph{Reward models.}
We evaluate both rule-based and model-based reward optimization. The rule-based tasks are GenEval for compositional text-to-image alignment~\citep{ghosh2023geneval} and OCR visual text rendering, using the same prompt splits and partial-credit reward design as the DiffusionNFT and FlowGRPO. The model-based rewards include PickScore~\citep{kirstain2023pickapic}, CLIPScore~\citep{hessel2021clipscore}, HPSv2.1~\citep{wu2023human}, Aesthetic score~\citep{schuhmann2022laion}, ImageReward~\citep{xu2023imagereward}, and UnifiedReward~\citep{wang2025unifiedreward}. Following DiffusionNFT, Pick-a-Pic prompts are used for preference-oriented training~\citep{kirstain2023pickapic}, while DrawBench prompts are reserved for out-of-domain evaluation~\citep{saharia2022photorealistic}.

\paragraph{Training protocol.}
We fine-tune the base model with LoRA~\citep{hu2022lora} using rank $r=32$, scaling factor $\alpha=64$, and learning rate $3 \times 10^{-4}$. Each training epoch contains 48 prompt groups, and each group samples $G=24$ images from the current rollout policy. Before constructing the mass shifts, rewards are centered by the mean of their prompt group and scaled by the population standard deviation over all rollout rewards in the current training iteration. For single-reward comparisons and ablations, rollouts use 10 sampling steps to match the efficient setting in DiffusionNFT. For multi-reward training and final evaluation, we use 40 sampling steps to reduce sampler-induced quality differences.

\subsubsection{Ablation on Forward Timestep Sampling}

We investigate the effect of different forward-timestep sampling strategies during training.
Across all settings, the sampled values are transformed using the same timestep-shift function:
\begin{equation}
\operatorname{shift}(x)
=
\frac{3x}{1+2x}.
\label{eq:timestep_shift}
\end{equation}

We compare the following three sampling schemes.

\medskip
\noindent\textbf{1. DiffusionNFT Original.}
Following the original DiffusionNFT implementation, we construct 10 uniformly spaced candidate points in $[0.001,1]$, apply the shift transformation, and uniformly sample 9 distinct timesteps without replacement:
\begin{align*}
x_j &= \operatorname{LinearSpace}(0.001,1,10)_j,
\qquad
T_j = \operatorname{shift}(x_j),
\quad j=0,\ldots,9,\\
\{t_0,\ldots,t_8\}
&\sim
\operatorname{SampleWithoutReplacement}
\left(
\{T_0,\ldots,T_9\},\,9
\right).
\end{align*}
This setting corresponds to the \textbf{green curve}.

\medskip
\noindent\textbf{2. Logit-Normal Sampling.}
Instead of sampling from a fixed discrete candidate set, we independently draw each timestep from a logit-normal distribution and then apply the same shift transformation:
\begin{align*}
z_i &\overset{\mathrm{iid}}{\sim} \mathcal N(0,1),
\qquad
x_i = \operatorname{sigmoid}(z_i),
\qquad
t_i = \operatorname{shift}(x_i),
\quad i=0,\ldots,8.
\end{align*}
This setting corresponds to the \textbf{gray curve}.

\medskip
\noindent\textbf{3. Uniform Sampling over $N$ Candidates.}
To examine whether the resolution of the discrete timestep candidate set affects training, we generalize the DiffusionNFT-style candidate construction to $N$ uniformly spaced points:
\begin{align*}
x_j &= \operatorname{LinearSpace}(0.001,1,N)_j,
\qquad
T_j = \operatorname{shift}(x_j),
\quad j=0,\ldots,N-1,\\
t_i &\overset{\mathrm{iid}}{\sim}
\operatorname{Uniform}
\left(
\{T_0,\ldots,T_{N-1}\}
\right),
\quad i=0,\ldots,8.
\end{align*}
The 9 timesteps are sampled independently
with replacement. We evaluate two resolutions:
\begin{itemize}
    \item $N=40$: \textbf{blue curve};
    \item $N=1000$: \textbf{red curve}.
\end{itemize}

\subsubsection{Mass-Shift Clip Ablation}

The original training objective is

\begin{equation}
\mathcal{L}
=
\left(
\Delta_{\mathrm{clip}}\mathcal{L}_{\mathrm{target}}
+
\lambda_{\mathrm{ref}}\mathcal{L}_{\mathrm{ref}}
\label{eq:origin clip factor}
\right),
\end{equation}

where $\Delta_{\mathrm{clip}}=5$ and $\lambda_{\mathrm{ref}}=10^{-4}$. Since training uses AdamW, scaling the entire loss by a positive constant approximately preserves the parameter update. Therefore, dividing the objective by $\Delta_{\mathrm{clip}}$ gives the approximately equivalent formulation

\begin{equation}
    \mathcal{L}
=\mathcal{L}_{\mathrm{target}}
+
\frac{\lambda_{\mathrm{ref}}}{\Delta_{\mathrm{clip}}}\mathcal{L}_{\mathrm{ref}},
\label{eq:move clip factor}
\end{equation}

We further evaluate a direct removal of $\Delta_{\mathrm{clip}}$ without rescaling $\lambda_{\mathrm{ref}}$:

\begin{equation}
    \mathcal{L}
=
\mathcal{L}_{\mathrm{target}}
+
\lambda_{\mathrm{ref}}\mathcal{L}_{\mathrm{ref}}.
\label{eq:omit clip factor}
\end{equation}


We compare these formulations under the single-reward GenEval setting to examine whether the explicit mass-shift-clip scaling is necessary and how the resulting change in target--reference balance affects training.

The corresponding one-sided importance weights are defined as follows.

\noindent{1. Positive Only}
\begin{align}

=
\begin{cases}
1+\Delta_i,
& \Delta_i>0,\\
1,
& \Delta_i\le0.
\end{cases}
\end{align}

\medskip
\noindent{2. Negative Only}
\begin{align}
W_i
=
\begin{cases}
1,
& \Delta_i\ge0,\\
1+\Delta_i,
& \Delta_i<0.
\end{cases}
\end{align}


\noindent\textbf{Adjusting $\beta$ for positive and negative advantage subsets.}
The mixture coefficient $\beta$ in the partial rollout coverage model
is defined as the probability mass of the old distribution that is
covered by the observed rollout samples. In the full rollout case,
$\beta_{\mathrm{all}}$ denotes the coverage of the complete set of $K$
samples. In many settings we take $\beta_{\mathrm{all}}=1$, which means
that the observed rollout samples are assumed to represent the entire
old distribution up to the empirical approximation.

Under $\beta_{\mathrm{all}}=1$, the old distribution is approximated as
\begin{align}
\pi^{\mathrm{o}}(\mathbf z)
\approx
\beta_{\mathrm{all}}\,\pi_{\mathcal{D}}(\mathbf z)
=
\frac{1}{K}\sum_{i=1}^{K}\delta_{\mathbf z_i},
\end{align}
so each observed sample carries an equal probability mass
$1/K$.

Now suppose we select a subset $S\subseteq\{1,\dots,K\}$ of size
$K_S$, for example the samples with positive advantage ($A>0$) or
negative advantage ($A<0$). The remaining $K-K_S$ samples are not
discarded; they are treated as part of the unobserved background
population. Thus the old distribution should be re-written as
\begin{align}
\pi^{\mathrm{o}}(\mathbf z)
=
(1-\beta_S)\,\pi_{\mathrm{bg}}(\mathbf z)
+
\beta_S\,\pi_{\mathcal{S}}(\mathbf z),
\end{align}
where $\pi_{\mathcal{S}}$ is the empirical distribution over the
selected subset, and $\beta_S$ is the probability mass covered by that
subset.

Since the full rollout set was assumed to cover mass
$\beta_{\mathrm{all}}$, and each of the $K$ original samples carries
mass $\beta_{\mathrm{all}}/K$, the selected subset covers mass
\begin{align}
\beta_S
=
\beta_{\mathrm{all}}\,\frac{K_S}{K}.
\end{align}
When $\beta_{\mathrm{all}}=1$, this reduces to
\begin{align}
\boxed{
\beta_S
=
\frac{K_S}{K}
}.
\end{align}
Therefore, if only positive-advantage samples are used,
$\beta_{\mathrm{pos}}=K_{\mathrm{pos}}/K$; if only negative-advantage
samples are used, $\beta_{\mathrm{neg}}=K_{\mathrm{neg}}/K$.

            \leftarrow

            \left(

            \Delta_{\mathrm{clip}}
            \right)$; the rest remains unchanged. That is, normalization and loss calculation still use the samples obtained from the entire rollout.
    \item \textbf{red curve}: Only negative. Line 12 in Algorithm~\ref{alg:velocity-add-delete} has been changed to $\Delta_{j,k}

\begin{algorithm}
\caption{Reinforced Flow Matching with Subset Selection}
\label{alg:velocity-subset}
\begin{algorithmic}[1]
\Require Initial model $\theta_0$, reward function $R$, prompt distribution
$p(c)$, Total prompts each training iteration $C$, rollout size for each prompt $K$, batch size $B$, total size $D = KC$, 
mass-shift clip $\Delta_{\mathrm{clip}}$, reference regularization
$\lambda_{\mathrm{ref}}$, EMA rate $\eta$, reward-scale constant $\epsilon_R$, and numerical constant $\epsilon_{\mathrm{alg}}$.
\State $\theta,\theta_{\mathrm{old}},\theta_{\mathrm{ref}}
\leftarrow\theta_0$.

\For{each training iteration}
    \For{each prompt $c_j\sim p(c)$ (Total C prompts each iteration.)}
        \State Sample $K$ clean rollout samples
        $\{\mathbf{x}_{0}^{j,k}\}_{k=1}^{K}$
        with $\theta$ conditioned on $c_j$.
        \State Compute rewards
        $R_{j,k}\leftarrow R(\mathbf{x}_{0}^{j,k},c_j)$
        for $k=1,\ldots,K$.
    \EndFor

    \State Compute the prompt-wise reward means
    $\bar R_{c_j}\leftarrow K^{-1}\sum_{k=1}^{K}R_{j,k}$
    for $j=1,\ldots,C$.
    \State Compute the global reward mean
    $\bar R\leftarrow D^{-1}\sum_{j=1}^{C}\sum_{k=1}^{K}R_{j,k}$.
    \State Compute the global reward scale
    $\sigma_R\leftarrow
    \sqrt{D^{-1}\sum_{j=1}^{C}\sum_{k=1}^{K}(R_{j,k}-\bar R)^2}
    +\epsilon_R$.

    \For{each prompt $c_j$, $j=1,\ldots,C$}
        \For{$k=1,\ldots,K$}
            \State $\Delta_{j,k}
            \leftarrow
            \frac{1}{\Delta_{\mathrm{clip}}}
            \operatorname{clip}\left(
            \frac{R_{j,k}-\bar R_{c_j}}{\sigma_R},
            -\Delta_{\mathrm{clip}},\Delta_{\mathrm{clip}}\right)$.
        \EndFor
        
        \State \textbf{Select subset} $S_j$ based on the sign of $\Delta$:
        
        \State 
        $\displaystyle
        S_j =
        \begin{cases}
        \{k : \Delta_{j,k}>0\}, & \text{positive-only},\\
        \{k : \Delta_{j,k}<0\}, & \text{negative-only}.
        \end{cases}$
        \State $K_{c_j}^{S}\leftarrow |S_j|$. % <-- changed
        
        % \State Set $\beta_{c_j}^{S} \leftarrow K_{c_j}^{S}/K$. % <-- changed
        \State Set $\beta_{c_j}^{S} 1.0$. % <-- changed
        \State $\displaystyle
        \bar Z_{c_j}^{S}
        \leftarrow
        1 + \frac{1}{K_{c_j}^{S}}\sum_{k\in S_j} \Delta_{j,k}$. % <-- changed

        \For{$k\in S_j$} % <-- changed: only selected samples enter the buffer
            \State $W(\mathbf{x}_{0}^{j,k},c_j) \leftarrow 1+\Delta_{j,k}$.
            \State Add $(c_j, \mathbf{x}_{0}^{j,k}, W, \bar Z_{c_j}^{S}, \beta_{c_j}^{S})$ to $\mathcal{D}^{S}$.
        \EndFor
    \EndFor

    \For{each minibatch
    $\{(c_i,\mathbf{x}_i^0,t_i,W_i,\bar Z_{c_i}^{S},\beta_{c_i}^{S})\}_{i=1}^{B}\sim\mathcal{D}^{S}$} % <-- changed: sample only from selected subset
        \State Sample $\boldsymbol{\epsilon}_i\sim\mathcal{N}(\mathbf{0},\mathbf{I})$
        and set $\mathbf{x}_i^{t_i}\leftarrow (1-t_i)\mathbf{x}_i^0 + t_i\boldsymbol{\epsilon}_i$.
        \State $\mathbf{v}_i \leftarrow \boldsymbol{\epsilon}_i - \mathbf{x}_i^0$.
        \State $\mathbf{v}_i^{\theta}\leftarrow \mathbf{v}_{\theta}(\mathbf{x}_i^{t_i},c_i,t_i)$.
        \State $\mathbf{v}_i^{\mathrm{old}}\leftarrow \mathbf{v}_{\theta_{\mathrm{old}}}(\mathbf{x}_i^{t_i},c_i,t_i)$.
        \State $\mathbf{v}_i^{\mathrm{ref}}\leftarrow \mathbf{v}_{\theta_{\mathrm{ref}}}(\mathbf{x}_i^{t_i},c_i,t_i)$.

        \State $\widetilde{\alpha}_i\leftarrow \frac{1}{\mathtt{sg}[\operatorname{mean}|\mathbf v_i-\mathbf v_i^{\theta}|]+\epsilon_{\mathrm{alg}}}$.
        \State $\alpha_i\leftarrow \frac{\widetilde{\alpha}_i}{B^{-1}\sum_{j=1}^{B}\widetilde{\alpha}_j}$.

        \State $\mathbf{v}_{i}^{target}
        \leftarrow
        \mathbf{v}_i^{\mathrm{old}}
        +
        \beta_{c_i}^{S}
        \left(
        \frac{W_i}{\bar Z_{c_i}^{S}} - 1
        \right)
        \alpha_i
        (\mathbf{v}_i - \mathbf{v}_i^{\mathrm{old}})$. % <-- changed: use subset-specific β and Z

        \State $\mathcal{L}_{\mathrm{target}}
        \leftarrow
        \frac{1}{B}\sum_{i=1}^{B} t_i
        \|\mathbf{v}_i^{\theta} - \mathbf{v}_{i}^{target}\|_2^2$.

        \State $\mathcal{L}_{\mathrm{ref}}
        \leftarrow
        \frac{1}{B}\sum_{i=1}^{B}
        \|\mathbf{v}_i^{\theta} - \mathbf{v}_i^{\mathrm{ref}}\|_2^2$.

        \State $\mathcal{L}
        \leftarrow
        \frac{1}{N_{acc}}(\Delta_{\mathrm{clip}}\mathcal{L}_{\mathrm{target}}
        + \lambda_{\mathrm{ref}}\mathcal{L}_{\mathrm{ref}})$.

        \State Backpropagate $\mathcal{L}$ and accumulate gradients without updating $\theta$.
    \EndFor

    \State Update $\theta$ once using the accumulated gradients.
    \State $\theta_{\mathrm{old}}\leftarrow \eta\theta_{\mathrm{old}}+(1-\eta)\theta$.
\EndFor
\end{algorithmic}
\end{algorithm}


\subsubsection{Asymmetric Scaling for Positive and Negative Mass Shifts}

For the $D=CK$ rollout samples in the current training iteration, let the
global reward mean and population standard deviation be

\begin{align}
\bar R
&=
\frac{1}{D}
\sum_{j=1}^{C}\sum_{k=1}^{K}R_{j,k},\\
\sigma_R
&=
\sqrt{
\frac{1}{D}
\sum_{j=1}^{C}\sum_{k=1}^{K}
(R_{j,k}-\bar R)^2
}
+\epsilon_R.
\end{align}

The same $\sigma_R$ is shared by every prompt group in the iteration, while
each reward is centered by its prompt-group mean
$\bar R_{c_j}=K^{-1}\sum_{k=1}^{K}R_{j,k}$.

To isolate the effect of asymmetric scaling between positive and negative mass shifts, we apply a fixed scaling factor $c>0$ to the normalization scale:

\begin{align}
\sigma_+ = c\sigma_R, \quad
\sigma_- = \frac{\sigma_R}{c}.
\end{align}

For a sample $i$ conditioned on prompt $c_i$, the resulting signed mass shift
is

\begin{equation}
\Delta_i^{(c)}=
\begin{cases}
\displaystyle
\frac{1}{\Delta_{\mathrm{clip}}}
\operatorname{clip}
\left(
\frac{R_i-\bar R_{c_i}}{c\sigma_R},
0,
\Delta_{\mathrm{clip}}
\right),
& R_i-\bar R_{c_i}>0,\\[10pt]
\displaystyle
\frac{1}{\Delta_{\mathrm{clip}}}
\operatorname{clip}
\left(
\frac{R_i-\bar R_{c_i}}{\sigma_R/c},
-\Delta_{\mathrm{clip}},
0
\right),
& R_i-\bar R_{c_i}\le 0.
\end{cases}
\end{equation}

We evaluate the following values of the scaling factor:

\begin{equation}
c \in
\left\{
\frac{1}{\sqrt{2}},
0.9,
1.0,
1.11,
\sqrt{2}
\right\}.
\end{equation}

Here, $c=1$ exactly recovers the symmetric mass-shift construction under the
same prompt centering and global reward scale. Values $c>1$ emphasize negative
mass shifts, whereas values $c<1$ emphasize positive mass shifts.

\subsection{A Unified View of Diffusion RL Objectives}
\label{sec:velocity_target_objectives}

We revisit existing RL objectives for flow matching models from a unified
velocity target perspective. Although these methods are motivated by different
RL principles, we show that they can all be interpreted as specifying: (i) an
effective velocity target for each generated sample, and (ii) a reward- or
advantage-dependent weight that determines how strongly the current model should
match or avoid this target.

We focus on one generated sample $i \in {1, \cdots, G}$ at timestep $t$.
% and omit timestep
% averaging and implementation details that are not essential to this view. 
Let
\[
\mathbf{v}_i^\theta
=
\mathbf{v}_\theta(\mathbf{x}_{i}^t,t,c_i),
\qquad
\mathbf{v}_i^{\mathrm{old}}
=
\mathbf{v}_{\theta_{\mathrm{old}}}(\mathbf{x}_{i}^t,t,c_i),
\]
denote the current and old velocity, respectively. Let
$\mathbf{v}_i$ denote the sample $i$ velocity, i.e., 
\begin{equation}
\mathbf{x}_{i}^t
=
(1-t)\mathbf{x}_i^t
+
t\boldsymbol{\epsilon}_i,
\qquad
\mathbf{v}_i
=
\boldsymbol{\epsilon}_i-\mathbf{x}_i^0 .
\end{equation}

Under this notation, a broad class of diffusion/flow RL objectives can be
viewed through the following  form:
\begin{equation}
\label{eq:unified_form}
\ell_i(\theta)
\approx
\kappa_i(A_i,t)
\left\|
\mathbf{v}_i^\theta
-
\mathbf{\tau}_i
\left(
A_i,
\mathbf{v}_i,
\mathbf{v}_i^{\mathrm{old}},
t
\right)
\right\|^2
+
\mathcal{R}_i(\theta),
\end{equation}
where $\mathbf{\tau}_i(\cdot)$ is the pseudo target function, it receives advantage $A_i$, currrent, old velocity $\mathbf{v}_i^{\theta}, \mathbf{v}_i^{old}$, and timestep $t$ as inputs.


$\kappa_i(A_i,t)$ is the weight, receives advantage $A_i$ and timestep $t$ as inputs. Intuitively, it
determines how strongly the current model should match or
avoid this target.

% and $\mathbf{v}_i^{\mathrm{ref}}$ denotes the velocity
% prediction of a frozen reference model.

The second term $\mathcal{R}_i(\theta)$  is the 
regularization term, commonly used to prevent the fine-tuned model
from drifting too far from the reference velocity field. The term
denotes additional proximal constraints, such as the
GRPO-style clipping of the likelihood ratio in Flow-GRPO. DiffusionNFT and
AWM use MSE regularization with reference model prediction.

We now recast Flow-GRPO in the unified velocity-target form of
Eq.~\eqref{eq:unified_form}. We keep the sample index $i$ and timestep $t$
fixed and temporarily omit the group average over $i$ and the time average
over $t$, which are constant with respect to the local loss decomposition.

Flow-GRPO optimizes
\begin{equation}
\label{eq:flowgrpo_per_sample_obj}
\mathcal{J}_i(\theta)
=
\min\bigl(r^i_t(\theta),
\operatorname{clip}(r^i_t(\theta),1-\varepsilon,1+\varepsilon)\bigr)
\hat{A}^i_t
-
\beta\,
D_{\mathrm{KL}}\bigl(\pi_\theta(\cdot\mid \vx^i_t,\vc)
\,\|\,
\pi_{\mathrm{ref}}(\cdot\mid \vx^i_t,\vc)\bigr),
\end{equation}
where
\begin{equation}
r^i_t(\theta)
=
\frac{p_\theta(\vx^i_{t-1}\mid \vx^i_t,\vc)}
{p_{\theta_{\mathrm{old}}}(\vx^i_{t-1}\mid \vx^i_t,\vc)} .
\end{equation}
In the unclipped region, the first term reduces to
$r^i_t(\theta)\,\hat{A}^i_t$. The following derivation is based on this
local approximation, which is exact for the gradient when the ratio lies
inside $[1-\varepsilon,1+\varepsilon]$.

Flow-GRPO replaces the deterministic flow ODE with the reverse SDE
\begin{equation}
\dd \vx_t
=
\left[
\vv_t(\vx_t)
-
\frac{\sigma_t^2}{2}\nabla\log p_t(\vx_t)
\right]\dd t
+
\sigma_t\,\dd \vw .
\end{equation}
For rectified flow, this becomes
\begin{equation}
\dd \vx_t
=
\left[
\vv_t(\vx_t)
+
\frac{\sigma_t^2}{2t}\bigl(\vx_t+(1-t)\vv_t(\vx_t)\bigr)
\right]\dd t
+
\sigma_t\,\dd \vw .
\end{equation}
Using the Euler--Maruyama discretization with step size $\Delta t$, the
policy is an isotropic Gaussian:
\begin{equation}
\label{eq:flowgrpo_update_rule}
\vx_{t+\Delta t}
=
\vx_t
+
\Delta t
\left[
\frac{\sigma_t^2}{2t}\vx_t
+
\left(1+\frac{\sigma_t^2(1-t)}{2t}\right)\vv_\theta(\vx_t,t,\vc)
\right]
+
\sigma_t\sqrt{\Delta t}\,\epsilon,
\qquad
\epsilon\sim\mathcal N(0,I).
\end{equation}
In this paper, \(\sigma_t = a\sqrt{\frac{t}{1-t}}\). Substituting this into
the coefficient of \(\vv_\theta\) yields
\[
1+\frac{\sigma_t^2(1-t)}{2t}
=
1+\frac{a^2}{2},
\]
which is a constant independent of \(t\). The conditional mean of the policy
is therefore
\begin{equation}
\bar{\vx}_{t+\Delta t,\theta}
=
\vx_t
+
\Delta t\left[
\frac{\sigma_t^2}{2t}\vx_t
+
\left(1+\frac{a^2}{2}\right)\vv_\theta
\right],
\end{equation}
and the policy is
\begin{equation}
\pi_\theta(\vx_{t-1}\mid \vx_t,\vc)
=
\mathcal N\bigl(\vx_{t-1};\,
\bar{\vx}_{t+\Delta t,\theta},\,
\sigma_t^2\Delta t\,I\bigr).
\end{equation}

The log-ratio is
\begin{equation}
\log r^i_t(\theta)
=
-\frac{1}{2\sigma_t^2\Delta t}
\left[
\left\|\vx_{t-1}-\bar{\vx}_{t+\Delta t,\theta}\right\|^2
-
\left\|\vx_{t-1}-\bar{\vx}_{t+\Delta t,\theta_{\mathrm{old}}}\right\|^2
\right].
\end{equation}
Since \(\vx_{t-1}\) and the old mean are independent of \(\theta\),
\begin{equation}
\nabla_\theta\!\left[\hat{A}^i_t\log r^i_t(\theta)\right]
=
-\frac{\hat{A}^i_t}{2\sigma_t^2\Delta t}
\nabla_\theta
\left\|\vx_{t-1}-\bar{\vx}_{t+\Delta t,\theta}\right\|^2 .
\end{equation}
Therefore, up to a constant gradient term, the policy-gradient part of
Eq.~\eqref{eq:flowgrpo_per_sample_obj} is equivalent to
\begin{equation}
\ell_i^{\mathrm{ratio}}(\theta)
=
\frac{\hat{A}^i_t}{2\sigma_t^2\Delta t}
\left\|\vx_{t-1}-\bar{\vx}_{t+\Delta t,\theta}\right\|^2 .
\end{equation}

Substituting the expression for \(\bar{\vx}_{t+\Delta t,\theta}\), we have
\begin{equation}
\vx_{t-1}-\bar{\vx}_{t+\Delta t,\theta}
=
\vx_{t-1}-\vx_t
-\Delta t\,\frac{\sigma_t^2}{2t}\vx_t
-\Delta t\left(1+\frac{a^2}{2}\right)\vv_\theta .
\end{equation}
Factoring out \(-\Delta t\left(1+\frac{a^2}{2}\right)\) gives
\begin{equation}
\vx_{t-1}-\bar{\vx}_{t+\Delta t,\theta}
=
-\Delta t\left(1+\frac{a^2}{2}\right)
\left[
\vv_\theta
+
\frac{\vx_t-\vx_{t-1}
+\Delta t\,\frac{\sigma_t^2}{2t}\vx_t}
{\Delta t\left(1+\frac{a^2}{2}\right)}
\right].
\end{equation}
Hence
\begin{equation}
\left\|\vx_{t-1}-\bar{\vx}_{t+\Delta t,\theta}\right\|^2
=
\Delta t^2\left(1+\frac{a^2}{2}\right)^2
\left\|
\vv_\theta
-
\bm{\tau}_i
\right\|^2,
\end{equation}
where the pseudo-target is
\begin{equation}
\bm{\tau}_i
=
\frac{\vx_{t-1}-\vx_t
-\Delta t\,\frac{\sigma_t^2}{2t}\vx_t}
{\Delta t\left(1+\frac{a^2}{2}\right)}.
\end{equation}
Using the sampling relation
\begin{equation}
\vx_{t-1}-\vx_t
=
\Delta t\left[
\frac{\sigma_t^2}{2t}\vx_t
+
\left(1+\frac{a^2}{2}\right)\vv_{\theta_{\mathrm{old}}}
\right]
+
\sigma_t\sqrt{\Delta t}\,\epsilon,
\end{equation}
we obtain
\begin{equation}
\label{eq:flowgrpo_pseudo_target}
\bm{\tau}_i^{\mathrm{Flow-GRPO}}
=
\mathbf{v}_i^{\mathrm{old}}
+
\frac{\sigma_t}
{\sqrt{\Delta t}\left(1+\frac{a^2}{2}\right)}\,\epsilon_i .
\end{equation}
Thus the pseudo-target is the old velocity prediction displaced by a
stochastic term proportional to the exploration noise.

Substituting the squared-norm factor into the ratio loss gives
\begin{equation}
\ell_i^{\mathrm{ratio}}(\theta)
=
\hat{A}^i_t\,
\frac{\Delta t\left(1+\frac{a^2}{2}\right)^2}{2\sigma_t^2}
\left\|
\mathbf{v}_i^\theta-\bm{\tau}_i^{\mathrm{Flow-GRPO}}
\right\|^2,
\end{equation}
where \(\mathbf{v}_i^\theta=\vv_\theta(\vx^i_t,t,\vc_i)\). Therefore
\begin{equation}
\label{eq:flowgrpo_weight}
\kappa_i^{\mathrm{Flow-GRPO}}
=
\hat{A}^i_t\,
\frac{\Delta t\left(1+\frac{a^2}{2}\right)^2}{2\sigma_t^2}
=
\hat{A}^i_t\,
\frac{\Delta t\left(1+\frac{a^2}{2}\right)^2(1-t)}{2a^2 t}.
\end{equation}

\paragraph{KL regularization.}
The KL divergence between the Gaussian policies
\(\pi_\theta\) and \(\pi_{\mathrm{ref}}\) has the closed form
\begin{equation}
D_{\mathrm{KL}}\bigl(\pi_\theta\|\pi_{\mathrm{ref}}\bigr)
=
\frac{\Delta t}{2}
\left(
\frac{\sigma_t(1-t)}{2t}
+
\frac{1}{\sigma_t}
\right)^2
\left\|
\vv_\theta(\vx_t,t,\vc)
-
\vv_{\mathrm{ref}}(\vx_t,t,\vc)
\right\|^2 .
\end{equation}
Substituting \(\sigma_t = a\sqrt{\frac{t}{1-t}}\) and simplifying,
\begin{equation}
\frac{\sigma_t(1-t)}{2t}
+
\frac{1}{\sigma_t}
=
\sqrt{\frac{1-t}{t}}
\left(
\frac{a}{2}
+
\frac{1}{a}
\right),
\end{equation}
and therefore
\begin{equation}
D_{\mathrm{KL}}\bigl(\pi_\theta\|\pi_{\mathrm{ref}}\bigr)
=
\frac{\Delta t}{2}
\frac{1-t}{t}
\left(
\frac{a}{2}
+
\frac{1}{a}
\right)^2
\left\|
\vv_\theta(\vx_t,t,\vc)
-
\vv_{\mathrm{ref}}(\vx_t,t,\vc)
\right\|^2 .
\end{equation}
Equivalently,
\begin{equation}
D_{\mathrm{KL}}\bigl(\pi_\theta\|\pi_{\mathrm{ref}}\bigr)
=
\frac{\Delta t (1-t)(a^2+2)^2}{8a^2 t}
\left\|
\vv_\theta(\vx_t,t,\vc)
-
\vv_{\mathrm{ref}}(\vx_t,t,\vc)
\right\|^2 .
\end{equation}

\paragraph{Unified form.}
Combining the above pieces, the local per-sample objective of Flow-GRPO
fits Eq.~\eqref{eq:unified_form} with
\begin{equation}
\boxed{
\begin{aligned}

&=

\frac{\Delta t\left(1+\frac{a^2}{2}\right)^2}{2\sigma_t^2}
=
\hat{A}^i_t\,
\frac{\Delta t\left(1+\frac{a^2}{2}\right)^2(1-t)}{2a^2 t},
\\

&=
\mathbf{v}_i^{\mathrm{old}}
+
\frac{\sigma_t}
{\sqrt{\Delta t}\left(1+\frac{a^2}{2}\right)}\,\epsilon_i
=
\mathbf{v}_i^{\mathrm{old}}
+
\frac{a}
{\sqrt{\Delta t}\left(1+\frac{a^2}{2}\right)}
\sqrt{\frac{t}{1-t}}\,\epsilon_i,
\\
\mathcal{R}_i^{\mathrm{Flow-GRPO}}(\theta)
&=
\beta\,
\frac{\Delta t}{2}

\right)^2
\left\|

\right\|^2
\\

\right\|^2 .
\end{aligned}
}
\end{equation}

\right)
\right\|^2
+

\end{equation}

This explicitly shows that Flow-GRPO does not use the clean velocity
\(\mathbf{v}_i\) as its target. Instead, the pseudo-target is the old
velocity prediction perturbed by the exploration noise. The reward enters
only through the advantage-scaled weight \(\hat{A}^i_t\), and the sign of
the advantage determines whether the squared loss attracts or repels the
current velocity from the noisy target.



\subsubsection{DiffusionNFT}
\label{sec:diffusionnft}

DiffusionNFT constructs positive and negative velocity branches around the old
velocity prediction:
\begin{equation}
\mathbf{v}_{i}^{+}
=
\mathbf{v}_i^{\mathrm{old}}
+
\beta
\left(
\mathbf{v}_i^\theta-\mathbf{v}_i^{\mathrm{old}}
\right),
\qquad
\mathbf{v}_{i}^{-}
=
\mathbf{v}_i^{\mathrm{old}}
-
\beta
\left(
\mathbf{v}_i^\theta-\mathbf{v}_i^{\mathrm{old}}
\right).
\end{equation}
Given an optimality reward $r_i\in[0,1]$, its sample-level loss is
\begin{equation}
\label{eq:nft_velocity_target_origin}
\ell_i^{\mathrm{NFT}}(\theta)
=
r_i
\left\|
\mathbf{v}_{i}^{+}
-
\mathbf{v}_i
\right\|^2
+
(1-r_i)
\left\|
\mathbf{v}_{i}^{-}
-
\mathbf{v}_i
\right\|^2 .
\end{equation}

This loss is equivalent, up to constants independent of $\theta$, to
\begin{equation}
\label{eq:nft_velocity_target_short}
\ell_i^{\mathrm{NFT}}(\theta)
=
\beta^2
\left\|
\mathbf{v}_i^\theta
-
\mathbf{\tau}_i^{\mathrm{NFT}}
\right\|^2,
\end{equation}
where
\begin{equation}
\label{eq:nft_pseudo_target_short}
\mathbf{\tau}_i^{\mathrm{NFT}}
=
\mathbf{v}_i^{\mathrm{old}}
+
\frac{2r_i-1}{\beta}
\left(
\mathbf{v}_i-\mathbf{v}_i^{\mathrm{old}}
\right).
\end{equation}

DiffusionNFT therefore fits Eq.~\ref{eq:unified_form}, with
\begin{equation}
\mathbf{\tau}_i
=
\mathbf{v}_i^{\mathrm{old}}
+
\frac{2r_i-1}{\beta}
\left(
\mathbf{v}_i-\mathbf{v}_i^{\mathrm{old}}
\right),
\qquad
\kappa_i
=
\beta^2 .
\end{equation}
Unlike Flow-GRPO, its reward directly determines where the effective target is placed along
the clean residual direction
\[
\mathbf{v}_i-\mathbf{v}_i^{\mathrm{old}}.
\]
When $r_i>0.5$, the target moves from the old velocity toward the clean
flow-matching target; when $r_i<0.5$, it is placed on the opposite side of the
old velocity. Thus, DiffusionNFT can be viewed as reward-conditioned velocity
target displacement.

The same interpretation can be expressed in the corresponding
$\mathbf{x}_0$-prediction space. Under the parameterization
\begin{equation}
\mathbf{x}_{0,i}^{\theta}
=
\mathbf{x}_{t,i}
-
t\mathbf{v}_i^\theta,
\qquad
\mathbf{x}_{0,i}^{\mathrm{old}}
=
\mathbf{x}_{t,i}
-
t\mathbf{v}_i^{\mathrm{old}},
\qquad
\mathbf{x}_{0,i}
=
\mathbf{x}_{t,i}
-
t\mathbf{v}_i,
\end{equation}
define the induced pseudo-target
\begin{equation}
x_{0,i}^{\mathrm{NFT}}
=
\mathbf{x}_{t,i}
-
t\mathbf{\tau}_i^{\mathrm{NFT}}.
\end{equation}
Substituting Eq.~\ref{eq:nft_pseudo_target_short} gives
\begin{align}
x_{0,i}^{\mathrm{NFT}}
&=
\mathbf{x}_{0,i}^{\mathrm{old}}
-
\frac{t(2r_i-1)}{\beta}
\left(
\mathbf{v}_i-\mathbf{v}_i^{\mathrm{old}}
\right)
\\
&=
\mathbf{x}_{0,i}^{\mathrm{old}}
+
\frac{2r_i-1}{\beta}
\left(
\mathbf{x}_{0,i}-\mathbf{x}_{0,i}^{\mathrm{old}}
\right).
\end{align}
Moreover,
\begin{equation}
\mathbf{v}_i^\theta-\mathbf{\tau}_i^{\mathrm{NFT}}
=
-\frac{1}{t}
\left(
\mathbf{x}_{0,i}^\theta
-
x_{0,i}^{\mathrm{NFT}}
\right),
\end{equation}
and in the implementation, $\ell_i^{\mathrm{NFT}}(\theta) = \frac{1}{\beta} \ell_i^{\mathrm{NFT}}(\theta)$,

hence the velocity-prediction losses in Eq.~\ref{eq:nft_velocity_target_origin} and
Eq.~\ref{eq:nft_velocity_target_short} are equivalently


\begin{equation}
\ell_i^{\mathrm{NFT}}(\theta)
=
\frac{1}{\beta t^2}(r_i
\left\|
\mathbf{x}_{i}^{+}
-
\mathbf{x}_i
\right\|^2
+
(1-r_i)
\left\|
\mathbf{x}_{i}^{-}
-
\mathbf{x}_i
\right\|^2) .
\end{equation}


\begin{equation}
\ell_i^{\mathrm{NFT}}(\theta)
=
\frac{\beta}{t^2}
\left\|
\mathbf{x}_{0,i}^{\theta}
-
x_{0,i}^{\mathrm{NFT}}
\right\|^2.
\end{equation}

\begin{equation}
x_{0,i}^{\mathrm{NFT}}
=
\mathbf{x}_{0,i}^{\mathrm{old}}
+
\frac{2r_i-1}{\beta}
\left(
\mathbf{x}_{0,i}-\mathbf{x}_{0,i}^{\mathrm{old}}
\right).
\end{equation}




\paragraph{Adaptive loss weighting in the implementation.}
The practical implementation of DiffusionNFT applies adaptive loss weighting
separately to the positive and negative branches. For a tensor
$\mathbf{u}\in\mathbb{R}^{D}$, define
\begin{equation}
\|\mathbf{u}\|^2
=
\frac{1}{D}\sum_{j=1}^{D}u_j^2,
\qquad
m(\mathbf{u})
=
\frac{1}{D}\sum_{j=1}^{D}|u_j|.
\end{equation}
The two branch predictions in $\mathbf{x}_0$-space are
\begin{align}
\mathbf{x}_{0,i}^{+}
&=
\mathbf{x}_{0,i}^{\mathrm{old}}
+
\beta
\left(
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{old}}
\right),
\\
\mathbf{x}_{0,i}^{-}
&=
\mathbf{x}_{0,i}^{\mathrm{old}}
-
\beta
\left(
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{old}}
\right).
\end{align}
The corresponding detached adaptive normalization factors are
\begin{align}
w_i^{+}(t)
&=
\operatorname{sg}
\left[
\max
\left(
m\left(
\mathbf{x}_{0,i}^{+}
-
\mathbf{x}_{0,i}
\right),
\epsilon
\right)
\right],
\\
w_i^{-}(t)
&=
\operatorname{sg}
\left[
\max
\left(
m\left(
\mathbf{x}_{0,i}^{-}
-
\mathbf{x}_{0,i}
\right),
\epsilon
\right)
\right].
\label{eq:origin-weight-factor}
\end{align}
Up to an additional global advantage scaling factor, the implementation uses
the sample-level objective
\begin{align}
\label{eq:nft_adaptive_separate}
\ell_{i,\mathrm{sep}}^{\mathrm{NFT\text{-}AW}}
=
\frac{1}{\beta}
\Bigg[
&
\frac{r_i}{w_i^{+}(t)}
\left\|
\mathbf{x}_{0,i}^{+}
-
\mathbf{x}_{0,i}
\right\|^2
+
\frac{1-r_i}{w_i^{-}(t)}
\left\|
\mathbf{x}_{0,i}^{-}
-
\mathbf{x}_{0,i}
\right\|^2
\Bigg].
\end{align}
The common factor $1/\beta$ follows the implementation and affects only the
overall loss scale.



\paragraph{Exact single-branch form.}Since
$w_i^{+}(t)$ and $w_i^{-}(t)$ are detached, completing the square in
Eq.~\ref{eq:nft_adaptive_separate} gives the following equality of gradients:
\begin{align}
\label{eq:nft_adaptive_single_gradient}
\nabla_\theta
\ell_{i,\mathrm{sep}}^{\mathrm{NFT\text{-}AW}}
=
\nabla_\theta
\Bigg\{
&\beta
\left(
\frac{r_i}{w_i^{+}(t)}
+
\frac{1-r_i}{w_i^{-}(t)}
\right)
\Bigg\|
\mathbf{x}_{0,i}^{\theta}
\nonumber\\
&\quad-
\left[
\mathbf{x}_{0,i}^{\mathrm{old}}
+
\frac{
\displaystyle
\frac{r_i}{w_i^{+}(t)}
-
\frac{1-r_i}{w_i^{-}(t)}
}{
\displaystyle
\beta
\left(
\frac{r_i}{w_i^{+}(t)}
+
\frac{1-r_i}{w_i^{-}(t)}
\right)
}
\left(
\mathbf{x}_{0,i}
-
\mathbf{x}_{0,i}^{\mathrm{old}}
\right) \right]
\Bigg\|^2
\Bigg\}.
\end{align}
The omitted difference between the two losses is independent of $\theta$ and
therefore has no effect on training. This expression shows the two effects of
the original adaptive factors directly. Their weighted inverse sum controls
the overall gradient scale, while their weighted inverse difference changes
the pseudo-target. 


\paragraph{Direct post-merge adaptive weighting.}
A much simpler choice is to apply the same normalization directly to the
single-branch residual:
\begin{equation}
\label{eq:nft_postmerge_adaptive}
\ell_{i,\mathrm{post}}^{\mathrm{NFT\text{-}AW}}
=
\beta
\frac{
\left\|
\mathbf{x}_{0,i}^{\theta}
-
x_{0,i}^{\mathrm{NFT}}
\right\|^2
}{
\operatorname{sg}
\left[
\max
\left(
m\left(
\mathbf{x}_{0,i}^{\theta}
-
x_{0,i}^{\mathrm{NFT}}
\right),
\epsilon
\right)
\right]
}.
\end{equation}
The leading $\beta$ matches the current single-branch implementation. This
objective is not strictly equivalent to Eq.~\ref{eq:nft_adaptive_separate},
because it uses one residual and cannot reproduce the target change caused by
unequal $w_i^{+}(t)$ and $w_i^{-}(t)$. Its denominator is the
error of the prediction that is actually optimized. 






\paragraph{Branch-free adaptive weighting.}
The adaptive weight should measure the prediction difficulty of sample \(i\) at
timestep \(t\). In the original NFT implementation, this difficulty is
estimated from the two branch predictions in
Eq.~\ref{eq:origin-weight-factor}. Since both branch predictions are
independent of the reward, their reconstruction errors relative to the clean
target provide stable estimates of sample and timestep difficulty. The reward
only determines how the two branch errors are combined.

This property is weakened by direct post-merge adaptive weighting. Let
\begin{equation}
A_i=2r_i-1,
\end{equation}
and define the single NFT pseudo-target as
\begin{equation}
\mathbf{x}_{0,i}^{\mathrm{NFT}}
=
\mathbf{x}_{0,i}^{\mathrm{old}}
-
\frac{A_i}{\beta}
\left(
\mathbf{x}_{0,i}^{\mathrm{old}}
-
\mathbf{x}_{0,i}
\right).
\end{equation}
Its fitting residual is
\begin{equation}
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{NFT}}
=
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{old}}
+
\frac{A_i}{\beta}
\left(
\mathbf{x}_{0,i}^{\mathrm{old}}
-
\mathbf{x}_{0,i}
\right).
\label{eq:nft_single_target_residual}
\end{equation}
Using this residual directly as the adaptive scale makes the estimated
difficulty strongly reward-dependent. When \(A_i\approx0\), or equivalently
\(r_i\approx1/2\), the pseudo-target approaches the old prediction and the
residual becomes dominated by
\(\mathbf{x}_{0,i}^{\theta}-\mathbf{x}_{0,i}^{\mathrm{old}}\). It may therefore
be small simply because the current policy remains close to the old policy,
even when the old reconstruction error
\(\mathbf{x}_{0,i}^{\mathrm{old}}-\mathbf{x}_{0,i}\) is large. In this case,
the adaptive factor no longer measures the actual difficulty of the sample and
timestep.

The factor \(1/\beta\) in
Eq.~\ref{eq:nft_single_target_residual} also introduces an artificial scale
dependence. We first remove it by multiplying the residual by \(\beta\):
\begin{equation}
\beta
\left(
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{NFT}}
\right)
=
\beta
\left(
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{old}}
\right)
+
A_i
\left(
\mathbf{x}_{0,i}^{\mathrm{old}}
-
\mathbf{x}_{0,i}
\right).
\end{equation}
However, rescaling alone is insufficient: when \(A_i\approx0\), the old
reconstruction error still disappears from this residual. We therefore add an
old-error anchor whose contribution increases as the advantage approaches
zero. For each tensor element \(j\), define
\begin{align}
q_{i,j}(r_i,t)
&=
\beta^2
\left(
x_{0,i,j}^{\theta}
-
x_{0,i,j}^{\mathrm{NFT}}
\right)^2
+
\left(1-A_i^2\right)
\left(
x_{0,i,j}^{\mathrm{old}}
-
x_{0,i,j}
\right)^2
\nonumber\\
&=
\Big[
\beta
\left(
x_{0,i,j}^{\theta}
-
x_{0,i,j}^{\mathrm{old}}
\right)
+
A_i
\left(
x_{0,i,j}^{\mathrm{old}}
-
x_{0,i,j}
\right)
\Big]^2
\nonumber\\
&\quad+
\left(1-A_i^2\right)
\left(
x_{0,i,j}^{\mathrm{old}}
-
x_{0,i,j}
\right)^2.
\label{eq:nft_branchfree_second_moment}
\end{align}
The first term measures the fitting error of the actual pseudo-target after
removing the artificial \(1/\beta\) scaling. The second term restores the old
reconstruction error when the reward provides little directional information.
Its coefficient satisfies
\begin{equation}
1-A_i^2
=
4r_i(1-r_i),
\end{equation}
which is largest at \(r_i=1/2\) and vanishes at the decisive endpoints
\(r_i=0\) and \(r_i=1\). Thus, when \(\lvert A_i\rvert\approx1\), the scale
relies mainly on the pseudo-target fitting residual. When \(A_i\approx0\), the
anchor preserves the underlying sample and timestep difficulty.

The resulting detached scale is
\begin{equation}
w_i(t)
=
\operatorname{sg}
\left[
\max
\left(
\frac{1}{D}
\sum_{j=1}^{D}
\sqrt{q_{i,j}(r_i,t)},
\epsilon
\right)
\right],
\label{eq:nft_branchfree_weight}
\end{equation}
and the objective becomes
\begin{equation}
\label{eq:nft_branchfree_adaptive}
\ell_i^{\mathrm{NFT\text{-}AW}}
=
\beta
\frac{
\left\|
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{NFT}}
\right\|^2
}{
w_i(t)
}.
\end{equation}

This construction retains a single pseudo-target and a single adaptive weight
while preserving a stable estimate of sample and timestep difficulty. At the
beginning of a policy update, when
\(\mathbf{x}_{0,i}^{\theta}=\mathbf{x}_{0,i}^{\mathrm{old}}\), we have
\begin{equation}
q_{i,j}
=
\left(
x_{0,i,j}^{\mathrm{old}}
-
x_{0,i,j}
\right)^2
\end{equation}
for every reward. At the neutral reward \(r_i=1/2\),
\begin{equation}
q_{i,j}
=
\left(
x_{0,i,j}^{\mathrm{old}}
-
x_{0,i,j}
\right)^2
+
\beta^2
\left(
x_{0,i,j}^{\theta}
-
x_{0,i,j}^{\mathrm{old}}
\right)^2,
\end{equation}
so the scale does not collapse merely because the current policy remains close
to the old policy.

Finally, the proposed quantity has a direct connection to the original two
branch errors:
\begin{equation}
q_{i,j}(r_i,t)
=
r_i
\left(
x_{0,i,j}^{+}
-
x_{0,i,j}
\right)^2
+
(1-r_i)
\left(
x_{0,i,j}^{-}
-
x_{0,i,j}
\right)^2.
\label{eq:nft_branchfree_branch_identity}
\end{equation}

Therefore, the proposed branch-free factor preserves the reward-weighted
second moment of the original two branch errors, while requiring only one
pseudo-target and one adaptive scale during optimization.


\paragraph{Simplified clean-target adaptive weighting.}
If the adaptive factor is y intended to measure the current difficulty of
sample \(i\) at timestep \(t\), an even simpler alternative is
\begin{equation}
\label{eq:nft_clean_target_adaptive}
\ell_{i,\mathrm{clean}}^{\mathrm{NFT\text{-}AW}}
=
\beta
\frac{
\left\|
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{NFT}}
\right\|^2
}{
\operatorname{sg}
\left[
\max
\left(
m\left(
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}
\right),
\epsilon
\right)
\right]
}.
\end{equation}
Here the numerator still optimizes the reward-dependent NFT pseudo-target,
whereas the denominator measures the current clean-target reconstruction error
directly. Consequently, the adaptive scale depends on the sample, timestep,
and current model state, but is not distorted by the reward-dependent
displacement of the pseudo-target. In particular, it remains informative when
\(r_i\approx1/2\).





\subsubsection{Advantage Weighted Matching}
\label{sec:awm}

AWM  consider an on-policy update on a single sample drawn from
$\pi_{\theta}$. Let $\widehat{\pi}_{\theta}$ denote the ELBO-based surrogate of the sequence likelihood,
\begin{equation}
\nabla_{\theta}
\frac{\hat{\pi}_{\theta}(x_i^t \mid c)}
{\operatorname{sg}\left(\hat{\pi}_{\theta}(x_i^t \mid c)\right)}
\cdot A_i
=
\nabla_{\theta}\log \hat{\pi}_{\theta}(x_i^t \mid c)\cdot A_i
\approx
-\nabla_{\theta}
w_i  A_i
\left\|
\mathbf{v}^{\theta}_i-\mathbf{v}_i
\right\|^2,
\end{equation}
where $w_i=w(t)$ is a timestep-dependent weight. The local gradient-equivalent objective becomes
\begin{equation}
\label{eq:awm_velocity_target_short}
\ell_i^{\mathrm{AWM}}(\theta)
=
w_i A_i
\left\|
\mathbf{v}_i^\theta-\mathbf{v}_i
\right\|^2.
\end{equation}


Thus, AWM also fits Eq.~\ref{eq:unified_form}, with
\begin{equation}
\mathbf{\tau}_i
=
\mathbf{v}_i,
\qquad
\kappa_i
=
w_i A_i.
\end{equation}
AWM uses the flow matching velocity as its target. Reward does not move
the target itself; instead, the signed advantage changes the direction and
strength of the target. 
Positive-advantage samples pull the current
velocity toward the clean target, whereas negative-advantage samples push it
away by reversing the gradient of the squared-error term.



\textbf{Adding an old-velocity KL to AWM:}
\begin{equation}
\ell_i^{\mathrm{AWM+KL}}(\theta)
=
w_iA_i
\left\|
\mathbf{v}_i^\theta-\mathbf{v}_i
\right\|^2
+
\beta
\left\|
\mathbf{v}_i^\theta-\mathbf{v}_i^{\mathrm{old}}
\right\|^2 .
\end{equation}

Ignoring constants independent of $\theta$, objective can
be written as

\begin{equation}
\ell_i^{\mathrm{AWM+KL}}(\theta)
=
(w_iA_i+\beta)
\left\|
\mathbf{v}_i^\theta
\right\|^2
-
2
\left(\mathbf{v}_i^\theta\right)^\top
\left(
w_iA_i\mathbf{v}_i+\beta\mathbf{v}_i^{\mathrm{old}}
\right)
+
\mathrm{const.}
\end{equation}

When $w_iA_i+\beta>0$, completing the square gives
\begin{equation}
\ell_i^{\mathrm{AWM+KL}}(\theta)
=
(w_iA_i+\beta)
\left\|
\mathbf{v}_i^\theta
-
\widetilde{\mathbf{v}}_i^{\mathrm{AWM+KL}}
\right\|^2
+
\mathrm{const.},
\end{equation}
where
\begin{equation}
\widetilde{\mathbf{v}}_i^{\mathrm{AWM+KL}}
=
\frac{
w_iA_i\mathbf{v}_i+\beta\mathbf{v}_i^{\mathrm{old}}
}{
w_iA_i+\beta
} = \mathbf{v}_i^{\mathrm{old}} + \frac{w_iA_i}{w_iA_i+\beta} (\mathbf{v}_i-\mathbf{v}_i^{\mathrm{old}}) .
\end{equation}

\textbf{X-prediction $\rightarrow$ V-prediction}

\begin{equation}
\alpha = \frac{1}{\operatorname{sg}\!\left[\operatorname{mean}\left|\mathbf{v}-\mathbf{v}^{\mathrm{old}}\right|\right]}
\end{equation}

\begin{equation}
\mathbf{v}^{\mathrm{target}} = \mathbf{v}^{\mathrm{old}} + \beta (w - 1)\left(\mathbf{v}-\mathbf{v}^{\mathrm{old}}\right)
\end{equation}

\begin{equation}
\mathcal{L}_{\mathrm{policy}} = \operatorname{mean}_{\mathrm{batch}}\!\left[ t \alpha \cdot \left\|\mathbf{v}^{\theta}-\mathbf{v}^{\mathrm{target}}\right\|^2 \right]
\end{equation}


\textbf{Implementation of our formulation:}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.75\linewidth]{imgs/ablation-3-alpha-in-target-recordalpha.png}
    \caption{The batch mean of $\alpha_{old}$ in B.1 experiment.}
    \label{fig:placeholder}
\end{figure}


According to our theoretical derivation, $\alpha_t(\mathbf{x}_t,\mathbf{z})$ is a conditional-to-marginal density ratio  $\frac{ p_t(\mathbf{x}_t|\mathbf{z}) }{ p_t(\mathbf{x}_t) }$ satisfying
$\mathbb{E}_{\mathbf z\sim\pi}[\alpha_t(\mathbf{x}_t,\mathbf z)]=1$.
However, the adaptive factor used in our current implementation is not numerically normalized in this way. Empirically, $\alpha_{\mathrm{old}}$ typically has a batch mean around $20$--$30$, with values ranging approximately from $2$to$100$.

We therefore first compute the original adaptive factor

\begin{equation}
\alpha_{\mathrm{old}}
=\frac{1}{
\operatorname{sg}\left[
\operatorname{mean}
\left|
\mathbf{v}-\mathbf{v}^{\mathrm{old}}
\right|
\right]
},
\end{equation}

and normalize it within each batch as

\begin{equation}
\bar{\alpha}_{\mathrm{old}}
=\frac{
\alpha_{\mathrm{old}}
}{
\operatorname{mean}_{\mathrm{batch}}
\left(\alpha_{\mathrm{old}}\right)
}.
\end{equation}

Thus,
$\operatorname{mean}_{\mathrm{batch}}(\bar{\alpha}_{\mathrm{old}})=1$,
making $\bar{\alpha}_{\mathrm{old}}$ a more appropriate empirical approximation of the theoretically derived posterior correction factor. We insert this normalized factor into the velocity correction:

\begin{equation}
\mathbf{v}^{\mathrm{target}}
=\mathbf{v}^{\mathrm{old}}
+
\beta (w-1)
\bar{\alpha}_{\mathrm{old}}
\left(
\mathbf{v}-\mathbf{v}^{\mathrm{old}}
\right).
\end{equation}

\noindent\textbf{Why retaining $\alpha_{\mathrm{old}}$ outside the MSE.}

For the previous verified single-target formulation in B.1,

\begin{equation}
\mathbf v^{\mathrm{target}}
=
\mathbf v^{\mathrm{old}}
+
\beta(w-1)
\left(
\mathbf v-\mathbf v^{\mathrm{old}}
\right),
\end{equation}

\begin{equation}
\mathcal L_{\mathrm{policy}}
=
\operatorname{mean}_{\mathrm{batch}}
\left[
t\alpha_{\mathrm{old}}
\left\|
\mathbf v^\theta-\mathbf v^{\mathrm{target}}
\right\|^2
\right].
\end{equation}

Its per-sample gradient is proportional to

\begin{equation}
2t\alpha_{\mathrm{old}}
\left[
\mathbf v^\theta-\mathbf v^{\mathrm{old}}
-
\beta(w-1)
\left(
\mathbf v-\mathbf v^{\mathrm{old}}
\right)
\right].
\end{equation}

In our formulation, the normalized $\bar{\alpha}_{\mathrm{old}}$ is introduced into the velocity correction:

\begin{equation}
\mathbf v^{\mathrm{target}}
=
\mathbf v^{\mathrm{old}}
+
\beta(w-1)
\bar{\alpha}_{\mathrm{old}}
\left(
\mathbf v-\mathbf v^{\mathrm{old}}
\right).
\end{equation}

And the outer $\alpha_{\mathrm{old}}$ is removed, the gradient becomes proportional to

\begin{equation}
2t
\left[
\mathbf v^\theta-\mathbf v^{\mathrm{old}}
-
\beta(w-1)
\bar{\alpha}_{\mathrm{old}}
\left(
\mathbf v-\mathbf v^{\mathrm{old}}
\right)
\right].
\end{equation}

Since $\bar{\alpha}_{\mathrm{old}}$ has batch mean $1$, it only controls the relative strength of the velocity correction and does not influence the overall gradient scale. 

Because the empirical mean of $\alpha_{\mathrm{old}}$ is around $20$--$30$, removing it would substantially reduce the overall gradient magnitude compared with the previous single-target formulation in B.1. And it will change the relationship between $L_{policy}$ and $L_{ref}$. Therefore, we retain $\alpha_{\mathrm{old}}$ outside the MSE:

\begin{equation}
\mathcal L_{\mathrm{policy}}
=
\operatorname{mean}_{\mathrm{batch}}
\left[
t\alpha_{\mathrm{old}}
\left\|
\mathbf v^\theta-\mathbf v^{\mathrm{target}}
\right\|^2
\right].
\end{equation}

\begin{equation}
\mathbf v^{\mathrm{target}}
=
\mathbf v^{\mathrm{old}}
+
\beta(w-1)
\bar{\alpha}_{\mathrm{old}}
\left(
\mathbf v-\mathbf v^{\mathrm{old}}
\right).
\end{equation}

The normalized $\bar{\alpha}_{\mathrm{old}}$ inside the target introduces the theoretically motivated posterior correction, while the original $\alpha_{\mathrm{old}}$ outside the MSE preserves approximately the gradient scale of the previous single-target objective.

\subsection{The Effect of $\Delta_{\mathrm{clip}}$ in the Loss Function}
\begin{equation}
\mathcal{L}_{\mathrm{policy}}
=
\frac{1}{\beta}
\operatorname{mean}_{\mathrm{batch}}
\left[
\frac{w}{2}
\frac{
\left\|
\hat{\mathbf{x}}_0^+-\mathbf{x}_0
\right\|^2
}{W^+}
+
\left(1-\frac{w}{2}\right)
\frac{
\left\|
\hat{\mathbf{x}}_0^--\mathbf{x}_0
\right\|^2
}{W^-}
\right],
\end{equation}


\begin{align}
\Delta
&=
\operatorname{clip}
\left(
\frac{R-\bar R}{\sigma_R},
-\Delta_{\mathrm{clip}},
\Delta_{\mathrm{clip}}
\right),\\
w&=1+\frac{\Delta}{\Delta_{\mathrm{clip}}}.
\end{align}

\begin{align}
\Delta_{\mathrm{clip}}\mathcal{L}_{\mathrm{policy}}
=\frac{1}{\beta}
\operatorname{mean}_{\mathrm{batch}}
\left[
\frac{\Delta_{\mathrm{clip}}}{2}(
\frac{
\left\|
\hat{\mathbf{x}}_0^+-\mathbf{x}_0
\right\|^2
}{W^+}
+\frac{
\left\|
\hat{\mathbf{x}}_0^--\mathbf{x}_0
\right\|^2
}{W^-}
)
\\
\quad+
\frac{\Delta}{2}(
\frac{
\left\|
\hat{\mathbf{x}}_0^+-\mathbf{x}_0
\right\|^2
}{W^+}
-\frac{
\left\|
\hat{\mathbf{x}}_0^--\mathbf{x}_0
\right\|^2
}{W^-}
)
\right],
\end{align}


The original objective is

\begin{equation}
\mathcal{L}_{\mathrm{old}}
=
\Delta_{\mathrm{clip}}\mathcal{L}_{\mathrm{policy}}
+
\lambda_{\mathrm{KL}}\mathcal{L}_{\mathrm{KL}}.
\end{equation}

We instead consider

\begin{equation}
\mathcal{L}_{\mathrm{new}}
=
\mathcal{L}_{\mathrm{policy}}
+
\frac{\lambda_{\mathrm{KL}}}{\Delta_{\mathrm{clip}}}
\mathcal{L}_{\mathrm{KL}}
=
\frac{1}{\Delta_{\mathrm{clip}}}
\mathcal{L}_{\mathrm{old}}.
\end{equation}

Therefore, this modification does not change the relative weighting between the policy loss and the KL regularization. It only globally rescales the loss by $1/\Delta_{\mathrm{clip}}$.

\paragraph{Gradient scaling.}

Since $\Delta_{\mathrm{clip}}$ is independent of $\theta$,

\begin{equation}
g_{\mathrm{new}}
=
\nabla_\theta \mathcal{L}_{\mathrm{new}}
=
\frac{1}{\Delta_{\mathrm{clip}}}
g_{\mathrm{old}}.
\end{equation}

Thus, before gradient clipping, the two objectives differ only by a constant gradient scale.

\paragraph{Interaction with gradient clipping.}

For global gradient clipping,

\begin{equation}
\operatorname{Clip}(g,C)
=
g\min\left(1,\frac{C}{\|g\|_2}\right),
\end{equation}

using the same threshold $C$ may break the scaling equivalence: $g_{\mathrm{old}}$ may be clipped while $g_{\mathrm{new}}$ remains unclipped.

To preserve identical clipping behavior, the threshold should be scaled accordingly:

\begin{equation}
C_{\mathrm{new}}
=
\frac{C_{\mathrm{old}}}{\Delta_{\mathrm{clip}}}.
\end{equation}

Then

\begin{equation}
\operatorname{Clip}
\left(
\frac{g_{\mathrm{old}}}{\Delta_{\mathrm{clip}}},
\frac{C_{\mathrm{old}}}{\Delta_{\mathrm{clip}}}
\right)
=
\frac{1}{\Delta_{\mathrm{clip}}}
\operatorname{Clip}
\left(
g_{\mathrm{old}},
C_{\mathrm{old}}
\right).
\end{equation}

For $\Delta_{\mathrm{clip}}=5$ and $C_{\mathrm{old}}=1.0$, the corresponding threshold is $C_{\mathrm{new}}=0.2$.

\paragraph{Impact on AdamW.}

If all gradients are uniformly scaled by $1/\Delta_{\mathrm{clip}}$, AdamW's first and second moments scale as

\begin{equation}
m_t^{\mathrm{new}}
=
\frac{1}{\Delta_{\mathrm{clip}}}m_t^{\mathrm{old}},
\qquad
v_t^{\mathrm{new}}
=
\frac{1}{\Delta_{\mathrm{clip}}^2}v_t^{\mathrm{old}}.
\end{equation}

Therefore, the normalized AdamW update is almost unchanged, except for the numerical stability term $\epsilon$:

\begin{equation}
\frac{\hat m_t^{\mathrm{new}}}
{\sqrt{\hat v_t^{\mathrm{new}}}+\epsilon}
=
\frac{\hat m_t^{\mathrm{old}}}
{\sqrt{\hat v_t^{\mathrm{old}}}
+
\Delta_{\mathrm{clip}}\epsilon}.
\end{equation}

Hence, loss scaling is approximately equivalent to replacing

\begin{equation}
\epsilon
\rightarrow
\Delta_{\mathrm{clip}}\epsilon.
\end{equation}

Since $\epsilon$ is typically very small, this effect is expected to be negligible. The main practical difference therefore comes from gradient clipping rather than AdamW itself.

The complete training objective is

\begin{equation}
\mathcal{L}_{\mathrm{total}}
=
\Delta_{\mathrm{clip}}\mathcal{L}_{\mathrm{policy}}
+
\lambda_{\mathrm{ref}}\mathcal{L}_{\mathrm{ref}},
\end{equation}

where

\begin{equation}
\mathcal{L}_{\mathrm{ref}}
=
\operatorname{mean}_{\mathrm{batch}}
\left[
\left\|
\mathbf{v}_{\theta}
-
\mathbf{v}_{\mathrm{ref}}
\right\|^2
\right].
\end{equation}

The policy loss is

\begin{equation}

\frac{1}{\beta}

\section{Possible Acceleration Strategies}
Without changing any algorithms, list some possible engineering strategies that could speed up training and test them out.

In each epoch, sampling uses \(48\) prompts \(\times\) \(24\) images \(=\) \(1152\) images, i.e., \(144\) images per GPU across \(16\) sampling iterations. Reward computation runs the full GenEval pipeline, including Mask2Former detection and CLIP color classification, on all \(1152\) images. Training uses \(16\) micro-batches \(\times\) \(72\) images \(\times\) \(9\) timesteps, with \(3\) Transformer forward passes and \(1\) backward pass per timestep, corresponding to the old policy, the default trainable policy, and the reference model without LoRA.

Sampling requires about \(16 \times 10 \times 9 = 1440\) forward units. Training requires about \(16 \times 9 \times 3 \times 72 = 31104\) forward units and \(10368\) backward units. Thus training is more than \(20\times\) the cost of sampling.

\subsection{Compiling the Transformer with \texttt{torch.compile} (estimated total speedup 20--35\%)}
The training phase performs \(27\) forward passes per \(72\)-image batch, and the sampling phase uses small batches over \(10\) steps, both of which incur substantial kernel-launch overhead. Applying \texttt{torch.compile} to \texttt{transformer\_ddp.module}, with \texttt{dynamic=True} or separate compilation for the sampling and training shapes because batch sizes change, can accelerate both phases. Since PEFT's \texttt{set\_adapter("old"/"default")} and \texttt{disable\_adapter()} only replace weights and do not alter graph structure, compiled graphs can typically be reused.

\subsection{Fixing DataLoader Overhead in GenEval Color Classification (estimated reward-phase speedup \(5\)--\(20\times\), total speedup 8--20\%)}
The most obvious engineering inefficiency is in the color classification routine at \texttt{flow\_grpo/gen\_eval.py:126}: it creates a new \texttt{DataLoader(..., num\_workers=4)} for every image and every color class. This results in hundreds of \texttt{DataLoader} instantiations and worker-process spawns per epoch per GPU even though each call classifies only a dozen crops. Without changing the scoring logic, one can collect all color crops of the entire image batch and run a single CLIP forward pass with the same model, templates, and argmax logic, yielding essentially identical scores.

The overlap analysis reveals that the test split is a compositional generalization benchmark. At the level of object classes, attribute values, and even individual entities with all attributes, the overlap is high: all 80 object classes and all attribute values (colors, counts, positions) appear in both splits, and 83.67\% of individual test entities exist in the training set. However, when considering complete combinations---either pairwise entity interactions or whole-sample compositions---the overlap drops dramatically to $0.33\%$ and $0.18\%$, respectively. Moreover, the prompt exact-match overlap is $0\%$, confirming that no textual description is reused.

The compositional breakdown further supports this interpretation: although 85.53\% of test samples consist entirely of entities that were seen during training, only 46.11\% have all pairwise interactions previously observed. 53.89\% of test samples combine known entities into novel interactions, which is the core challenge of compositional generalization. Additionally, 14.47\% of test samples contain at least one individual entity not present in the training set, primarily due to the \texttt{counting} subtask, where all $(\text{class}, \text{count})$ pairs are disjoint between the splits, and the \texttt{single\_object} subtask, which has no training samples at all.
