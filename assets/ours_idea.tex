\subsection{A Unified View of Diffusion RL Objectives}
\label{sec:velocity_target_objectives}

We revisit existing RL objectives for flow matching models from a unified
velocity target perspective. Although these methods are motivated by different
RL principles, we show that they can all be interpreted as specifying: (i) an
effective velocity target for each generated sample, and (ii) a reward- or
advantage-dependent weight that determines how strongly the current model should
match or avoid this target.

We focus on one generated sample $i \in {1, \cdots, G}$ at timestep $t$.
% and omit timestep
% averaging and implementation details that are not essential to this view. 
Let
\[
\mathbf{v}_i^\theta
=
\mathbf{v}_\theta(\mathbf{x}_{i}^t,t,c_i),
\qquad
\mathbf{v}_i^{\mathrm{old}}
=
\mathbf{v}_{\theta_{\mathrm{old}}}(\mathbf{x}_{i}^t,t,c_i),
\]
denote the current and old velocity, respectively. Let
$\mathbf{v}_i$ denote the sample $i$ velocity, i.e., 
\begin{equation}
\mathbf{x}_{i}^t
=
(1-t)\mathbf{x}_i^t
+
t\boldsymbol{\epsilon}_i,
\qquad
\mathbf{v}_i
=
\boldsymbol{\epsilon}_i-\mathbf{x}_i^0 .
\end{equation}

Under this notation, a broad class of diffusion/flow RL objectives can be
viewed through the following  form:
\begin{equation}
\label{eq:unified_form}
\ell_i(\theta)
\approx
\kappa_i(A_i,t)
\left\|
\mathbf{v}_i^\theta
-
\mathbf{\tau}_i
\left(
A_i,
\mathbf{v}_i,
\mathbf{v}_i^{\mathrm{old}},
t
\right)
\right\|^2
+
\mathcal{R}_i(\theta),
\end{equation}
where $\mathbf{\tau}_i(\cdot)$ is the pseudo target function, it receives advantage $A_i$, currrent, old velocity $\mathbf{v}_i^{\theta}, \mathbf{v}_i^{old}$, and timestep $t$ as inputs.


$\kappa_i(A_i,t)$ is the weight, receives advantage $A_i$ and timestep $t$ as inputs. Intuitively, it
determines how strongly the current model should match or
avoid this target.

% and $\mathbf{v}_i^{\mathrm{ref}}$ denotes the velocity
% prediction of a frozen reference model.

The second term $\mathcal{R}_i(\theta)$  is the 
regularization term, commonly used to prevent the fine-tuned model
from drifting too far from the reference velocity field. The term
denotes additional proximal constraints, such as the
GRPO-style clipping of the likelihood ratio in Flow-GRPO. DiffusionNFT and
AWM use MSE regularization with reference model prediction.



\subsubsection{Flow-GRPO}
\label{sec:flow_grpo}

Flow-GRPO starts from an policy-gradient objective over stochastic
denoising transitions. For one transition from timestep $t$ to $s$, the
sample-level objective (the following derivation corresponds to the first term in Eq.~\ref{eq:unified_form}) can be written as
\begin{equation}
\ell_i^{\mathrm{FG}}(\theta)
=
-
A_i
\rho_i(\theta),
\qquad
\rho_i(\theta)
=
\frac{
p_{\theta}(\mathbf{x}_i^s\mid \mathbf{x}_i^t,c_i)
}{
p_{\theta_{\mathrm{old}}}(\mathbf{x}_i^s\mid \mathbf{x}_i^t,c_i)
},
\end{equation}
where $A_i$ is the trajectory-level advantage. Assume that the reverse
transition is modeled as a Gaussian policy with shared covariance:
\begin{equation}
p_{\theta}(\mathbf{x}^{s}_{i}\mid \mathbf{x}^{t}_{i},c_i)
=
\mathcal{N}
\left(
\mathbf{x}^{s}_{i};
a_t\mathbf{x}^{t}_{i}+b_t\mathbf{v}_i^\theta,
\eta_t^2 I
\right)
\end{equation}
For a fixed sampled transition $(\mathbf{x}_i^t,\mathbf{x}_i^s)$, this Gaussian
mean induces a pseudo target:
\begin{equation}
\label{eq:flow_grpo_pseudo_target_short}
\mathbf{\tau}_i^{\mathrm{FG}}
=
\frac{\mathbf{x}^{s}_{i}-a_t\mathbf{x}^{t}_{i}}{b_t}
\end{equation}
Since
\begin{equation}
\mathbf{x}^{s}_{i}
=
a_t\mathbf{x}^{t}_{i}
+
b_t\mathbf{v}_i^{\mathrm{old}}
+
\eta_t\boldsymbol{\epsilon}_i,
\end{equation}
the pseudo target can also be written as
\begin{equation}
\label{eq:flow_grpo_target_short}
\mathbf{\tau}_i^{\mathrm{FG}}
=
\mathbf{v}_i^{\mathrm{old}}
+
\frac{\eta_t}{b_t}
\boldsymbol{\epsilon}_i .
\end{equation}
Thus, the Flow-GRPO target is a stochastic noise add velocity target induced by the sampled old-policy
transition.

Substituting Eq.~\ref{eq:flow_grpo_pseudo_target_short} into the Gaussian
likelihood gives
\begin{equation}
\rho_i(\theta)
=
C_i
\exp
\left[
-
\frac{b_t^2}{2\eta_t^2}
\left\|
\mathbf{v}_i^\theta
-
\mathbf{\tau}_i^{\mathrm{FG}}
\right\|^2
\right],
\end{equation}
where
\begin{equation}
C_i
=
\exp
\left[
\frac{b_t^2}{2\eta_t^2}
\left\|
\mathbf{v}_i^{\mathrm{old}}
-
\mathbf{\tau}_i^{\mathrm{FG}}
\right\|^2
\right]
\end{equation}
is independent of $\theta$. Therefore, the Flow-GRPO objective can be
viewed as an advantage-weighted function of the squared distance between
$\mathbf{v}_i^\theta$ and the transition-induced target
$\mathbf{\tau}_i^{\mathrm{FG}}$.

To connect it with the unified target-matching form, consider the gradient of
the sample objective with respect to the velocity prediction:
\begin{equation}
\nabla_{\mathbf{v}_i^\theta}
\ell_i^{\mathrm{FG}}(\theta)
=
2
\left(
A_i
\frac{b_t^2}{2\eta_t^2}
\rho_i(\theta)
\right)
\left(
\mathbf{v}_i^\theta
-
\mathbf{\tau}_i^{\mathrm{FG}}
\right).
\end{equation}
This has the same local gradient direction as a weighted squared-error objective
\begin{equation}
\kappa_i
\left\|
\mathbf{v}_i^\theta
-
\mathbf{\tau}_i^{\mathrm{FG}}
\right\|^2.
\end{equation}


In this sense, Flow-GRPO fits the unified form in
Eq.~\ref{eq:unified_form} with
\begin{equation}
\mathbf{\tau}_i
=
\mathbf{v}_i^{\mathrm{old}}
+
\frac{\eta_t}{b_t}
\boldsymbol{\epsilon}_i ,
\qquad
\kappa_i
=
A_i
\frac{b_t^2}{2\eta_t^2} \rho_i(\theta).
\end{equation}
The sign of $A_i$ determines whether the model is pulled toward or pushed away
from the pseudo target. A positive advantage makes gradient descent move
$\mathbf{v}_i^\theta$ toward the sampled transition-level target, whereas a
negative advantage reverses this direction. The main distinction from clean
flow-matching objectives is that this target contains transition noise through
$\frac{\eta_t}{b_t}\boldsymbol{\epsilon}_i$, rather than being defined by the
clean residual $\mathbf{v}_i-\mathbf{v}_i^{\mathrm{old}}$.



\subsubsection{DiffusionNFT}
\label{sec:diffusionnft}

DiffusionNFT constructs positive and negative velocity branches around the old
velocity prediction:
\begin{equation}
\mathbf{v}_{i}^{+}
=
\mathbf{v}_i^{\mathrm{old}}
+
\beta
\left(
\mathbf{v}_i^\theta-\mathbf{v}_i^{\mathrm{old}}
\right),
\qquad
\mathbf{v}_{i}^{-}
=
\mathbf{v}_i^{\mathrm{old}}
-
\beta
\left(
\mathbf{v}_i^\theta-\mathbf{v}_i^{\mathrm{old}}
\right).
\end{equation}
Given an optimality reward $r_i\in[0,1]$, its sample-level loss is
\begin{equation}
\ell_i^{\mathrm{NFT}}(\theta)
=
r_i
\left\|
\mathbf{v}_{i}^{+}
-
\mathbf{v}_i
\right\|^2
+
(1-r_i)
\left\|
\mathbf{v}_{i}^{-}
-
\mathbf{v}_i
\right\|^2 .
\end{equation}
This loss is equivalent, up to constants independent of $\theta$, to
\begin{equation}
\label{eq:nft_velocity_target_short}
\ell_i^{\mathrm{NFT}}(\theta)
=
\beta^2
\left\|
\mathbf{v}_i^\theta
-
\mathbf{\tau}_i^{\mathrm{NFT}}
\right\|^2,
\end{equation}
where
\begin{equation}
\label{eq:nft_pseudo_target_short}
\mathbf{\tau}_i^{\mathrm{NFT}}
=
\mathbf{v}_i^{\mathrm{old}}
+
\frac{2r_i-1}{\beta}
\left(
\mathbf{v}_i-\mathbf{v}_i^{\mathrm{old}}
\right).
\end{equation}

DiffusionNFT therefore fits Eq.~\ref{eq:unified_form}, with
\begin{equation}
\mathbf{\tau}_i
=
\mathbf{v}_i^{\mathrm{old}}
+
\frac{2r_i-1}{\beta}
\left(
\mathbf{v}_i-\mathbf{v}_i^{\mathrm{old}}
\right),
\qquad
\kappa_i
=
\beta^2 .
\end{equation}
Unlike Flow-GRPO, its reward directly determines where the effective target is placed along
the clean residual direction
\[
\mathbf{v}_i-\mathbf{v}_i^{\mathrm{old}}.
\]
When $r_i>0.5$, the target moves from the old velocity toward the clean
flow-matching target; when $r_i<0.5$, it is placed on the opposite side of the
old velocity. Thus, DiffusionNFT can be viewed as reward-conditioned velocity
target displacement.

The same interpretation can be expressed in the corresponding
$\mathbf{x}_0$-prediction space. Under the parameterization
\begin{equation}
\mathbf{x}_{0,i}^{\theta}
=
\mathbf{x}_{t,i}
-
t\mathbf{v}_i^\theta,
\qquad
\mathbf{x}_{0,i}^{\mathrm{old}}
=
\mathbf{x}_{t,i}
-
t\mathbf{v}_i^{\mathrm{old}},
\qquad
\mathbf{x}_{0,i}
=
\mathbf{x}_{t,i}
-
t\mathbf{v}_i,
\end{equation}
define the induced pseudo-target
\begin{equation}
x_{0,i}^{\mathrm{NFT}}
=
\mathbf{x}_{t,i}
-
t\mathbf{\tau}_i^{\mathrm{NFT}}.
\end{equation}
Substituting Eq.~\ref{eq:nft_pseudo_target_short} gives
\begin{align}
x_{0,i}^{\mathrm{NFT}}
&=
\mathbf{x}_{0,i}^{\mathrm{old}}
-
\frac{t(2r_i-1)}{\beta}
\left(
\mathbf{v}_i-\mathbf{v}_i^{\mathrm{old}}
\right)
\\
&=
\mathbf{x}_{0,i}^{\mathrm{old}}
+
\frac{2r_i-1}{\beta}
\left(
\mathbf{x}_{0,i}-\mathbf{x}_{0,i}^{\mathrm{old}}
\right).
\end{align}
Moreover,
\begin{equation}
\mathbf{v}_i^\theta-\mathbf{\tau}_i^{\mathrm{NFT}}
=
-\frac{1}{t}
\left(
\mathbf{x}_{0,i}^\theta
-
x_{0,i}^{\mathrm{NFT}}
\right),
\end{equation}
and hence the velocity-prediction loss in
Eq.~\ref{eq:nft_velocity_target_short} is equivalently
\begin{equation}
\ell_i^{\mathrm{NFT}}(\theta)
=
\frac{1}{t^2}(r_i
\left\|
\mathbf{x}_{i}^{+}
-
\mathbf{x}_i
\right\|^2
+
(1-r_i)
\left\|
\mathbf{x}_{i}^{-}
-
\mathbf{x}_i
\right\|^2) .
\end{equation}

\begin{equation}
\ell_i^{\mathrm{NFT}}(\theta)
=
\frac{\beta^2}{t^2}
\left\|
\mathbf{x}_{0,i}^{\theta}
-
x_{0,i}^{\mathrm{NFT}}
\right\|^2.
\end{equation}

\begin{equation}
x_{0,i}^{\mathrm{NFT}}
=
\mathbf{x}_{0,i}^{\mathrm{old}}
+
\frac{2r_i-1}{\beta}
\left(
\mathbf{x}_{0,i}-\mathbf{x}_{0,i}^{\mathrm{old}}
\right).
\end{equation}




\paragraph{Adaptive loss weighting in the implementation.}
The practical implementation of DiffusionNFT applies adaptive loss weighting
separately to the positive and negative branches. For a tensor
$\mathbf{u}\in\mathbb{R}^{D}$, define
\begin{equation}
\|\mathbf{u}\|^2
=
\frac{1}{D}\sum_{j=1}^{D}u_j^2,
\qquad
m(\mathbf{u})
=
\frac{1}{D}\sum_{j=1}^{D}|u_j|.
\end{equation}
The two branch predictions in $\mathbf{x}_0$-space are
\begin{align}
\mathbf{x}_{0,i}^{+}
&=
\mathbf{x}_{0,i}^{\mathrm{old}}
+
\beta
\left(
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{old}}
\right),
\\
\mathbf{x}_{0,i}^{-}
&=
\mathbf{x}_{0,i}^{\mathrm{old}}
-
\beta
\left(
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{old}}
\right).
\end{align}
The corresponding detached adaptive normalization factors are
\begin{align}
w_i^{+}(t)
&=
\operatorname{sg}
\left[
\max
\left(
m\left(
\mathbf{x}_{0,i}^{+}
-
\mathbf{x}_{0,i}
\right),
\epsilon
\right)
\right],
\\
w_i^{-}(t)
&=
\operatorname{sg}
\left[
\max
\left(
m\left(
\mathbf{x}_{0,i}^{-}
-
\mathbf{x}_{0,i}
\right),
\epsilon
\right)
\right].
\label{eq:origin-weight-factor}
\end{align}
Up to an additional global advantage scaling factor, the implementation uses
the sample-level objective
\begin{align}
\label{eq:nft_adaptive_separate}
\ell_{i,\mathrm{sep}}^{\mathrm{NFT\text{-}AW}}
=
\frac{1}{\beta}
\Bigg[
&
\frac{r_i}{w_i^{+}(t)}
\left\|
\mathbf{x}_{0,i}^{+}
-
\mathbf{x}_{0,i}
\right\|^2
+
\frac{1-r_i}{w_i^{-}(t)}
\left\|
\mathbf{x}_{0,i}^{-}
-
\mathbf{x}_{0,i}
\right\|^2
\Bigg].
\end{align}
The common factor $1/\beta$ follows the implementation and affects only the
overall loss scale.



\paragraph{Exact single-branch form.}Since
$w_i^{+}(t)$ and $w_i^{-}(t)$ are detached, completing the square in
Eq.~\ref{eq:nft_adaptive_separate} gives the following equality of gradients:
\begin{align}
\label{eq:nft_adaptive_single_gradient}
\nabla_\theta
\ell_{i,\mathrm{sep}}^{\mathrm{NFT\text{-}AW}}
=
\nabla_\theta
\Bigg\{
&\beta
\left(
\frac{r_i}{w_i^{+}(t)}
+
\frac{1-r_i}{w_i^{-}(t)}
\right)
\Bigg\|
\mathbf{x}_{0,i}^{\theta}
\nonumber\\
&\quad-
\left[
\mathbf{x}_{0,i}^{\mathrm{old}}
+
\frac{
\displaystyle
\frac{r_i}{w_i^{+}(t)}
-
\frac{1-r_i}{w_i^{-}(t)}
}{
\displaystyle
\beta
\left(
\frac{r_i}{w_i^{+}(t)}
+
\frac{1-r_i}{w_i^{-}(t)}
\right)
}
\left(
\mathbf{x}_{0,i}
-
\mathbf{x}_{0,i}^{\mathrm{old}}
\right) \right]
\Bigg\|^2
\Bigg\}.
\end{align}
The omitted difference between the two losses is independent of $\theta$ and
therefore has no effect on training. This expression shows the two effects of
the original adaptive factors directly. Their weighted inverse sum controls
the overall gradient scale, while their weighted inverse difference changes
the pseudo-target. 


\paragraph{Direct post-merge adaptive weighting.}
A much simpler choice is to apply the same normalization directly to the
single-branch residual:
\begin{equation}
\label{eq:nft_postmerge_adaptive}
\ell_{i,\mathrm{post}}^{\mathrm{NFT\text{-}AW}}
=
\beta
\frac{
\left\|
\mathbf{x}_{0,i}^{\theta}
-
x_{0,i}^{\mathrm{NFT}}
\right\|^2
}{
\operatorname{sg}
\left[
\max
\left(
m\left(
\mathbf{x}_{0,i}^{\theta}
-
x_{0,i}^{\mathrm{NFT}}
\right),
\epsilon
\right)
\right]
}.
\end{equation}
The leading $\beta$ matches the current single-branch implementation. This
objective is not strictly equivalent to Eq.~\ref{eq:nft_adaptive_separate},
because it uses one residual and cannot reproduce the target change caused by
unequal $w_i^{+}(t)$ and $w_i^{-}(t)$. Its denominator is the
error of the prediction that is actually optimized. 






\paragraph{Branch-free adaptive weighting.}
The adaptive weight should measure the prediction difficulty of sample \(i\) at
timestep \(t\). In the original NFT implementation, this difficulty is
estimated from the two branch predictions in
Eq.~\ref{eq:origin-weight-factor}. Since both branch predictions are
independent of the reward, their reconstruction errors relative to the clean
target provide stable estimates of sample and timestep difficulty. The reward
only determines how the two branch errors are combined.

This property is weakened by direct post-merge adaptive weighting. Let
\begin{equation}
A_i=2r_i-1,
\end{equation}
and define the single NFT pseudo-target as
\begin{equation}
\mathbf{x}_{0,i}^{\mathrm{NFT}}
=
\mathbf{x}_{0,i}^{\mathrm{old}}
-
\frac{A_i}{\beta}
\left(
\mathbf{x}_{0,i}^{\mathrm{old}}
-
\mathbf{x}_{0,i}
\right).
\end{equation}
Its fitting residual is
\begin{equation}
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{NFT}}
=
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{old}}
+
\frac{A_i}{\beta}
\left(
\mathbf{x}_{0,i}^{\mathrm{old}}
-
\mathbf{x}_{0,i}
\right).
\label{eq:nft_single_target_residual}
\end{equation}
Using this residual directly as the adaptive scale makes the estimated
difficulty strongly reward-dependent. When \(A_i\approx0\), or equivalently
\(r_i\approx1/2\), the pseudo-target approaches the old prediction and the
residual becomes dominated by
\(\mathbf{x}_{0,i}^{\theta}-\mathbf{x}_{0,i}^{\mathrm{old}}\). It may therefore
be small simply because the current policy remains close to the old policy,
even when the old reconstruction error
\(\mathbf{x}_{0,i}^{\mathrm{old}}-\mathbf{x}_{0,i}\) is large. In this case,
the adaptive factor no longer measures the actual difficulty of the sample and
timestep.

The factor \(1/\beta\) in
Eq.~\ref{eq:nft_single_target_residual} also introduces an artificial scale
dependence. We first remove it by multiplying the residual by \(\beta\):
\begin{equation}
\beta
\left(
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{NFT}}
\right)
=
\beta
\left(
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{old}}
\right)
+
A_i
\left(
\mathbf{x}_{0,i}^{\mathrm{old}}
-
\mathbf{x}_{0,i}
\right).
\end{equation}
However, rescaling alone is insufficient: when \(A_i\approx0\), the old
reconstruction error still disappears from this residual. We therefore add an
old-error anchor whose contribution increases as the advantage approaches
zero. For each tensor element \(j\), define
\begin{align}
q_{i,j}(r_i,t)
&=
\beta^2
\left(
x_{0,i,j}^{\theta}
-
x_{0,i,j}^{\mathrm{NFT}}
\right)^2
+
\left(1-A_i^2\right)
\left(
x_{0,i,j}^{\mathrm{old}}
-
x_{0,i,j}
\right)^2
\nonumber\\
&=
\Big[
\beta
\left(
x_{0,i,j}^{\theta}
-
x_{0,i,j}^{\mathrm{old}}
\right)
+
A_i
\left(
x_{0,i,j}^{\mathrm{old}}
-
x_{0,i,j}
\right)
\Big]^2
\nonumber\\
&\quad+
\left(1-A_i^2\right)
\left(
x_{0,i,j}^{\mathrm{old}}
-
x_{0,i,j}
\right)^2.
\label{eq:nft_branchfree_second_moment}
\end{align}
The first term measures the fitting error of the actual pseudo-target after
removing the artificial \(1/\beta\) scaling. The second term restores the old
reconstruction error when the reward provides little directional information.
Its coefficient satisfies
\begin{equation}
1-A_i^2
=
4r_i(1-r_i),
\end{equation}
which is largest at \(r_i=1/2\) and vanishes at the decisive endpoints
\(r_i=0\) and \(r_i=1\). Thus, when \(\lvert A_i\rvert\approx1\), the scale
relies mainly on the pseudo-target fitting residual. When \(A_i\approx0\), the
anchor preserves the underlying sample and timestep difficulty.

The resulting detached scale is
\begin{equation}
w_i(t)
=
\operatorname{sg}
\left[
\max
\left(
\frac{1}{D}
\sum_{j=1}^{D}
\sqrt{q_{i,j}(r_i,t)},
\epsilon
\right)
\right],
\label{eq:nft_branchfree_weight}
\end{equation}
and the objective becomes
\begin{equation}
\label{eq:nft_branchfree_adaptive}
\ell_i^{\mathrm{NFT\text{-}AW}}
=
\beta
\frac{
\left\|
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{NFT}}
\right\|^2
}{
w_i(t)
}.
\end{equation}

This construction retains a single pseudo-target and a single adaptive weight
while preserving a stable estimate of sample and timestep difficulty. At the
beginning of a policy update, when
\(\mathbf{x}_{0,i}^{\theta}=\mathbf{x}_{0,i}^{\mathrm{old}}\), we have
\begin{equation}
q_{i,j}
=
\left(
x_{0,i,j}^{\mathrm{old}}
-
x_{0,i,j}
\right)^2
\end{equation}
for every reward. At the neutral reward \(r_i=1/2\),
\begin{equation}
q_{i,j}
=
\left(
x_{0,i,j}^{\mathrm{old}}
-
x_{0,i,j}
\right)^2
+
\beta^2
\left(
x_{0,i,j}^{\theta}
-
x_{0,i,j}^{\mathrm{old}}
\right)^2,
\end{equation}
so the scale does not collapse merely because the current policy remains close
to the old policy.

Finally, the proposed quantity has a direct connection to the original two
branch errors:
\begin{equation}
q_{i,j}(r_i,t)
=
r_i
\left(
x_{0,i,j}^{+}
-
x_{0,i,j}
\right)^2
+
(1-r_i)
\left(
x_{0,i,j}^{-}
-
x_{0,i,j}
\right)^2.
\label{eq:nft_branchfree_branch_identity}
\end{equation}

Therefore, the proposed branch-free factor preserves the reward-weighted
second moment of the original two branch errors, while requiring only one
pseudo-target and one adaptive scale during optimization.


\paragraph{Simplified clean-target adaptive weighting.}
If the adaptive factor is only intended to measure the current difficulty of
sample \(i\) at timestep \(t\), an even simpler alternative is
\begin{equation}
\label{eq:nft_clean_target_adaptive}
\ell_{i,\mathrm{clean}}^{\mathrm{NFT\text{-}AW}}
=
\beta
\frac{
\left\|
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}^{\mathrm{NFT}}
\right\|^2
}{
\operatorname{sg}
\left[
\max
\left(
m\left(
\mathbf{x}_{0,i}^{\theta}
-
\mathbf{x}_{0,i}
\right),
\epsilon
\right)
\right]
}.
\end{equation}
Here the numerator still optimizes the reward-dependent NFT pseudo-target,
whereas the denominator measures the current clean-target reconstruction error
directly. Consequently, the adaptive scale depends on the sample, timestep,
and current model state, but is not distorted by the reward-dependent
displacement of the pseudo-target. In particular, it remains informative when
\(r_i\approx1/2\). Moreover, the adaptive scale itself requires neither the
two branch errors nor the additional old-error anchor in
Eq.~\ref{eq:nft_branchfree_second_moment}. This objective does not preserve the
exact two-branch gradient or the reward-weighted second-moment identity in
Eq.~\ref{eq:nft_branchfree_branch_identity}; rather, it is a minimal
difficulty-normalized single-target objective when such exact matching is not
required.





\subsubsection{Advantage Weighted Matching}
\label{sec:awm}

AWM  consider an on-policy update on a single sample drawn from
$\pi_{\theta}$. Let $\widehat{\pi}_{\theta}$ denote the ELBO-based surrogate of the sequence likelihood,
\begin{equation}
\nabla_{\theta}
\frac{\hat{\pi}_{\theta}(x_i^t \mid c)}
{\operatorname{sg}\left(\hat{\pi}_{\theta}(x_i^t \mid c)\right)}
\cdot A_i
=
\nabla_{\theta}\log \hat{\pi}_{\theta}(x_i^t \mid c)\cdot A_i
\approx
-\nabla_{\theta}
w_i  A_i
\left\|
\mathbf{v}^{\theta}_i-\mathbf{v}_i
\right\|^2,
\end{equation}
where $w_i=w(t)$ is a timestep-dependent weight. The local gradient-equivalent objective becomes
\begin{equation}
\label{eq:awm_velocity_target_short}
\ell_i^{\mathrm{AWM}}(\theta)
=
w_i A_i
\left\|
\mathbf{v}_i^\theta-\mathbf{v}_i
\right\|^2.
\end{equation}


Thus, AWM also fits Eq.~\ref{eq:unified_form}, with
\begin{equation}
\mathbf{\tau}_i
=
\mathbf{v}_i,
\qquad
\kappa_i
=
w_i A_i.
\end{equation}
AWM uses the flow matching velocity as its target. Reward does not move
the target itself; instead, the signed advantage changes the direction and
strength of the target. 
Positive-advantage samples pull the current
velocity toward the clean target, whereas negative-advantage samples push it
away by reversing the gradient of the squared-error term.



\textbf{Adding an old-velocity KL to AWM:}
\begin{equation}
\ell_i^{\mathrm{AWM+KL}}(\theta)
=
w_iA_i
\left\|
\mathbf{v}_i^\theta-\mathbf{v}_i
\right\|^2
+
\beta
\left\|
\mathbf{v}_i^\theta-\mathbf{v}_i^{\mathrm{old}}
\right\|^2 .
\end{equation}

Ignoring constants independent of $\theta$, objective can
be written as

\begin{equation}
\ell_i^{\mathrm{AWM+KL}}(\theta)
=
(w_iA_i+\beta)
\left\|
\mathbf{v}_i^\theta
\right\|^2
-
2
\left(\mathbf{v}_i^\theta\right)^\top
\left(
w_iA_i\mathbf{v}_i+\beta\mathbf{v}_i^{\mathrm{old}}
\right)
+
\mathrm{const.}
\end{equation}

When $w_iA_i+\beta>0$, completing the square gives
\begin{equation}
\ell_i^{\mathrm{AWM+KL}}(\theta)
=
(w_iA_i+\beta)
\left\|
\mathbf{v}_i^\theta
-
\widetilde{\mathbf{v}}_i^{\mathrm{AWM+KL}}
\right\|^2
+
\mathrm{const.},
\end{equation}
where
\begin{equation}
\widetilde{\mathbf{v}}_i^{\mathrm{AWM+KL}}
=
\frac{
w_iA_i\mathbf{v}_i+\beta\mathbf{v}_i^{\mathrm{old}}
}{
w_iA_i+\beta
} = \mathbf{v}_i^{\mathrm{old}} + \frac{w_iA_i}{w_iA_i+\beta} (\mathbf{v}_i-\mathbf{v}_i^{\mathrm{old}}) .
\end{equation}

\subsection{REINFORCED FLOW MATCHING}


\subsubsection{Flow Matching}

Let $\mathbf{x}_0\sim p_{\mathcal{D}}$ denote a clean sample from the
data distribution and let
$\boldsymbol{\epsilon}\sim\mathcal{N}(\mathbf{0},\mathbf{I})$ denote
Gaussian noise. We consider the linear probability path
\begin{align}
    \mathbf{x}_t
    =
    (1-t)\mathbf{x}_0
    +
    t\boldsymbol{\epsilon},
    \qquad
    t\sim\mathcal{U}(0,1),
\end{align}
with the corresponding conditional velocity
\begin{align}
    \mathbf{v}_t
    (\mathbf{x}_t\mid\mathbf{x}_0,\boldsymbol{\epsilon})
    =
    \boldsymbol{\epsilon}-\mathbf{x}_0.
\end{align}

A velocity model $\mathbf{v}_{\boldsymbol{\phi}}$ is trained using the
flow matching objective
\begin{align}
\mathcal{L}_{\mathrm{FM}}(\boldsymbol{\phi})
=
\mathbb{E}_{t}
\mathbb{E}_{\mathbf{x}_0\sim p_{\mathcal{D}},
\boldsymbol{\epsilon}\sim\mathcal{N}(\mathbf{0},\mathbf{I})}
\left[
\left\|
\mathbf{v}_{\boldsymbol{\phi}}(\mathbf{x}_t,t)
-
\mathbf{v}_t
(\mathbf{x}_t\mid\mathbf{x}_0,\boldsymbol{\epsilon})
\right\|_2^2
\right].
\end{align}

Under the squared-error objective, the optimal marginal velocity field
is the conditional average of all velocities passing through
the same intermediate state:
\begin{align}
\mathbf{v}^{*}(\mathbf{x}_t,t)
=
\mathbb{E}_{\mathbf{x}_0,\boldsymbol{\epsilon}}
\left[
\mathbf{v}_t
(\mathbf{x}_t\mid\mathbf{x}_0,\boldsymbol{\epsilon})
\mid
\mathbf{x}_t,t
\right].
\label{eq:optimal-fm-velocity}
\end{align}

For an empirical dataset, this conditional expectation can be written
as
\begin{align}
\mathbf{v}^{*}(\mathbf{x}_t,t)
=
\sum_{\mathbf{x}_0\in\mathcal{D}}
p(\mathbf{x}_0\mid\mathbf{x}_t,t)
\,
\mathbb{E}_{\boldsymbol{\epsilon}}
\left[
\mathbf{v}_t
(\mathbf{x}_t\mid\mathbf{x}_0,\boldsymbol{\epsilon})
\mid
\mathbf{x}_0,\mathbf{x}_t,t
\right].
\label{eq:empirical-optimal-velocity}
\end{align}

Therefore, the optimal velocity is not a uniform average over all clean
samples. The contribution of each sample depends on its posterior
probability conditioned on the current intermediate state
$(\mathbf{x}_t,t)$.


Our goal is to adjust the probability mass assigned to a set of samples
according to their rewards. We assume that every sample initially has
unit weight. For a selected set $\mathcal{D}_r$, we change the weight of
each sample $\mathbf{x}_0\in\mathcal{D}_r$ from $1$ to
$W(\mathbf{x}_0)$, while samples outside $\mathcal{D}_r$ retain their
original unit weights.

The total weighted mass of $\mathcal{D}_r$ is
\begin{align}
S_w(\mathcal{D}_r)
=
S(\mathcal{D}_r)
\mathbb{E}_{\mathbf{x}_0\sim p_{\mathcal{D}_r}}
\left[
W(\mathbf{x}_0)
\right].
\label{eq:weighted-size}
\end{align}

The exact reweighted velocity requires the state-conditioned
contribution of every clean sample. To obtain a tractable expression,
we approximate the posterior proportions conditioned on
$(\mathbf{x}_t,t)$ using the global empirical proportions of
$\mathcal{D}\setminus\mathcal{D}_r$ and $\mathcal{D}_r$. Under this
dataset-level approximation, the reweighted velocity is
\begin{align}
\mathbf{v}_r^*(\mathbf{x}_t,t)
\approx~&
\frac{
S(\mathcal{D}\setminus\mathcal{D}_r)
}{
S(\mathcal{D}\setminus\mathcal{D}_r)
+
S_w(\mathcal{D}_r)
}
\mathbb{E}_{\mathbf{x}_0\sim
p_{\mathcal{D}\setminus\mathcal{D}_r}}
\mathbb{E}_{\boldsymbol{\epsilon}}
\left[
\mathbf{v}_t
(\mathbf{x}_t\mid\mathbf{x}_0,\boldsymbol{\epsilon})
\mid
\mathbf{x}_0,\mathbf{x}_t,t
\right]
\nonumber\\
&+
\frac{
S(\mathcal{D}_r)
}{
S(\mathcal{D}\setminus\mathcal{D}_r)
+
S_w(\mathcal{D}_r)
}
\mathbb{E}_{\mathbf{x}_0\sim p_{\mathcal{D}_r}}
\left[
W(\mathbf{x}_0)
\cdot
\mathbb{E}_{\boldsymbol{\epsilon}}
\left[
\mathbf{v}_t
(\mathbf{x}_t\mid\mathbf{x}_0,\boldsymbol{\epsilon})
\mid
\mathbf{x}_0,\mathbf{x}_t,t
\right]
\right].
\label{eq:initial-reweighted-velocity}
\end{align}

Equation~\eqref{eq:initial-reweighted-velocity} directly represents our
motivation. Samples outside $\mathcal{D}_r$ retain their original mass,
whereas every sample in $\mathcal{D}_r$ changes its mass from $1$ to
$W(\mathbf{x}_0)$.

Using
\begin{align}
S(\mathcal{D}\setminus\mathcal{D}_r)
\mathbb{E}_{\mathbf{x}_0\sim
p_{\mathcal{D}\setminus\mathcal{D}_r}}
[\cdot]
&=
S(\mathcal{D})
\mathbb{E}_{\mathbf{x}_0\sim p_{\mathcal{D}}}
[\cdot]
-
S(\mathcal{D}_r)
\mathbb{E}_{\mathbf{x}_0\sim p_{\mathcal{D}_r}}
[\cdot],
\label{eq:set-decomposition}
\end{align}
we can rewrite
Eq.~\eqref{eq:initial-reweighted-velocity} as
\begin{align}
\mathbf{v}_r^*(\mathbf{x}_t,t)
\approx~&
\frac{
S(\mathcal{D})
}{
S(\mathcal{D})-S(\mathcal{D}_r)+S_w(\mathcal{D}_r)
}
\mathbb{E}_{\mathbf{x}_0\sim p_{\mathcal{D}}}
\mathbb{E}_{\boldsymbol{\epsilon}}
\left[
\mathbf{v}_t
(\mathbf{x}_t\mid\mathbf{x}_0,\boldsymbol{\epsilon})
\mid
\mathbf{x}_0,\mathbf{x}_t,t
\right]
\nonumber\\
&+
\frac{
S(\mathcal{D}_r)
}{
S(\mathcal{D})-S(\mathcal{D}_r)+S_w(\mathcal{D}_r)
}
\mathbb{E}_{\mathbf{x}_0\sim p_{\mathcal{D}_r}}
\left[
\left(
W(\mathbf{x}_0)-1
\right)
\cdot
\mathbb{E}_{\boldsymbol{\epsilon}}
\left[
\mathbf{v}_t
(\mathbf{x}_t\mid\mathbf{x}_0,\boldsymbol{\epsilon})
\mid
\mathbf{x}_0,\mathbf{x}_t,t
\right]
\right].
\label{eq:reweighted-full-decomposition}
\end{align}

We define
\begin{align}
\beta
&=
\frac{S(\mathcal{D}_r)}{S(\mathcal{D})},
\label{eq:beta-definition}
\\
\delta_r
&=
\mathbb{E}_{\mathbf{x}_0\sim p_{\mathcal{D}_r}}
\left[
W(\mathbf{x}_0)-1
\right].
\label{eq:delta-definition}
\end{align}

From Eq.~\eqref{eq:weighted-size}, we have
\begin{align}
S_w(\mathcal{D}_r)
=
S(\mathcal{D}_r)
\left(
1+\delta_r
\right).
\end{align}
Therefore,
\begin{align}
&S(\mathcal{D})-S(\mathcal{D}_r)+S_w(\mathcal{D}_r)=
S(\mathcal{D})(1+\beta\delta_r).
\label{eq:normalization-denominator}
\end{align}

Using the same dataset-level approximation to replace the full-data
average by the original optimal velocity, we obtain
\begin{align}
\mathbf{v}_r^*(\mathbf{x}_t,t)
\approx~&
\frac{1}{1+\beta\delta_r}
\mathbf{v}^{*}(\mathbf{x}_t,t)
\nonumber\\
&+
\frac{\beta}{1+\beta\delta_r}
\mathbb{E}_{\mathbf{x}_0\sim p_{\mathcal{D}_r}}
\left[
\left(
W(\mathbf{x}_0)-1
\right)
\cdot
\mathbb{E}_{\boldsymbol{\epsilon}}
\left[
\mathbf{v}_t
(\mathbf{x}_t\mid\mathbf{x}_0,\boldsymbol{\epsilon})
\mid
\mathbf{x}_0,\mathbf{x}_t,t
\right]
\right].
\label{eq:reweighted-velocity-decomposition}
\end{align}

We then use
\begin{align}
\frac{1}{1+\beta\delta_r}
=
1-
\frac{\beta\delta_r}{1+\beta\delta_r}
\end{align}
to write
\begin{align}
\mathbf{v}_r^*(\mathbf{x}_t,t)
\approx~&
\mathbf{v}^{*}(\mathbf{x}_t,t)
-
\frac{\beta\delta_r}{1+\beta\delta_r}
\mathbf{v}^{*}(\mathbf{x}_t,t)
\nonumber\\
&+
\frac{\beta}{1+\beta\delta_r}
\mathbb{E}_{\mathbf{x}_0\sim p_{\mathcal{D}_r}}
\left[
\left(
W(\mathbf{x}_0)-1
\right)
\cdot
\mathbb{E}_{\boldsymbol{\epsilon}}
\left[
\mathbf{v}_t
(\mathbf{x}_t\mid\mathbf{x}_0,\boldsymbol{\epsilon})
\mid
\mathbf{x}_0,\mathbf{x}_t,t
\right]
\right].
\label{eq:separated-normalization}
\end{align}

Since
\begin{align}
\delta_r\mathbf{v}^{*}(\mathbf{x}_t,t)
=
\mathbb{E}_{\mathbf{x}_0\sim p_{\mathcal{D}_r}}
\left[
\left(
W(\mathbf{x}_0)-1
\right)
\mathbf{v}^{*}(\mathbf{x}_t,t)
\right],
\end{align}
the latter two terms can be combined, yielding
\begin{align}
\mathbf{v}_r^*(\mathbf{x}_t,t)
\approx~&
\mathbf{v}^{*}(\mathbf{x}_t,t)
\nonumber\\
&+
\frac{\beta}{1+\beta\delta_r}
\mathbb{E}_{\mathbf{x}_0\sim p_{\mathcal{D}_r}}
\mathbb{E}_{\boldsymbol{\epsilon}}
\Big[
\left(
W(\mathbf{x}_0)-1
\right)
\cdot
\left(
\mathbf{v}_t
(\mathbf{x}_t\mid\mathbf{x}_0,\boldsymbol{\epsilon})
-
\mathbf{v}^{*}(\mathbf{x}_t,t)
\right)
\mid
\mathbf{x}_0,\mathbf{x}_t,t
\Big].
\label{eq:Reinforced-final}
\end{align}

Equation~\eqref{eq:Reinforced-final} shows that changing the
sample weight from $1$ to $W(\mathbf{x}_0)$ modifies the original
velocity through the corresponding sample-specific velocity
difference. When $W(\mathbf{x}_0)>1$, the sample receives additional
mass and its conditional velocity is reinforced. When
$W(\mathbf{x}_0)<1$, its original mass is reduced and the model moves
away from its conditional velocity. When $W(\mathbf{x}_0)=1$, the
sample produces no change.

\paragraph{Approximation assumptions.}

The derivation above contains several approximations. First, the exact
optimal velocity in Eq.~\eqref{eq:optimal-fm-velocity} is conditioned
on the current state $(\mathbf{x}_t,t)$. In
Eq.~\eqref{eq:initial-reweighted-velocity}, we replace the corresponding
state-dependent posterior proportions with global dataset proportions.
As a result, $\beta$ and $\delta_r$ are treated as independent of
$\mathbf{x}_t$ and $t$.


\subsection{Sample-Wise Reweighted Target}

For a clean rollout sample $\mathbf{x}_i^0$, we sample
$\boldsymbol{\epsilon}_i\sim\mathcal{N}(\mathbf{0},\mathbf{I})$ and
construct
\begin{align}
\mathbf{x}_i^{t_i}
=
(1-t_i)\mathbf{x}_i^0
+
t_i\boldsymbol{\epsilon}_i.
\end{align}

The old model predicts
\begin{align}
\mathbf{v}_i^{\mathrm{old}}
=
\mathbf{v}_{\boldsymbol{\theta}_{\mathrm{old}}}
(\mathbf{x}_i^{t_i},c_i,t_i),
\end{align}
from which its clean-sample prediction is
\begin{align}
\widehat{\mathbf{x}}_{0,i}^{\mathrm{old}}
=
\mathbf{x}_i^{t_i}
-
t_i\mathbf{v}_i^{\mathrm{old}}.
\end{align}

For the sampled linear path,
\begin{align}
\mathbf{x}_i^0
=
\mathbf{x}_i^{t_i}
-
t_i
\mathbf{v}_{t_i}
(\mathbf{x}_i^{t_i}
\mid
\mathbf{x}_i^0,\boldsymbol{\epsilon}_i).
\end{align}

Using one rollout sample to estimate the expectation in
Eq.~\eqref{eq:Reinforced-final}, the reweighted clean-sample
target becomes
\begin{align}
\overline{\mathbf{x}}_{0,i}
=
\widehat{\mathbf{x}}_{0,i}^{\mathrm{old}}
+
\frac{
\beta
\left(
W(\mathbf{x}_i^0,c_i)-1
\right)
}{
1+\beta\delta_r(c_i)
}
\left(
\mathbf{x}_i^0
-
\widehat{\mathbf{x}}_{0,i}^{\mathrm{old}}
\right).
\label{eq:reweighted-clean-target}
\end{align}

For a sample with $W(\mathbf{x}_i^0,c_i)>1$, the target moves from the
old prediction toward the clean rollout sample. For a sample with
$W(\mathbf{x}_i^0,c_i)<1$, the coefficient is negative and the target
moves away from the rollout sample. Here, $\delta_r(c_i)$ denotes the
prompt-group counterpart of Eq.~\eqref{eq:delta-definition}, evaluated
over rollout samples generated under the same prompt. As shown below,
the current centered linear weighting makes this quantity zero in the
idealized unclipped case and close to zero in the practical clipped
implementation.

\subsection{Reward-Based Sample Weighting}

For the $K$ rollout samples generated under the same prompt $c$, we
first standardize and clip their raw rewards:
\begin{align}
\overline{R}_c
&=
\frac{1}{K}
\sum_{k=1}^{K}R_k,
\\
Z_c
&=
\sqrt{
\frac{1}{K}
\sum_{k=1}^{K}
(R_k-\overline{R}_c)^2
+
\epsilon
},
\\
\widehat{A}_k
&=
\frac{1}{A}
\operatorname{clip}
\left(
\frac{R_k-\overline{R}_c}{Z_c},
-A,A
\right).
\label{eq:normalized-reward}
\end{align}
This normalization ensures that
$\widehat{A}_k\in[-1,1]$, where positive and negative values indicate
above- and below-average rewards, respectively.

We use linear weighting and directly add the normalized advantage to
the original unit weight:
\begin{align}
W(\mathbf{x}_0^k,c)
=
1+\widehat{A}_k.
\label{eq:linear-reward-weight}
\end{align}
The resulting weights satisfy
\begin{align}
W(\mathbf{x}_0^k,c)
\in
[0,2].
\end{align}
This mapping provides a direct additive interpretation:
$\widehat{A}_k=0$ preserves the original weight,
$\widehat{A}_k=1$ doubles the sample weight, and
$\widehat{A}_k=-1$ reduces the sample weight to zero. In practice, if
strictly positive weights are required for numerical stability, the
linear mapping is implemented as
\begin{align}
W(\mathbf{x}_0^k,c)
=
\max\left\{
\epsilon,\,
1+\widehat{A}_k
\right\}.
\label{eq:positive-linear-reward-weight}
\end{align}

\paragraph{Near-zero normalization shift under centered linear weighting.}
To clarify the value of $\delta_r$ under the weighting rule above,
first consider the standardized advantage before clipping,
\begin{align}
\widetilde{A}_k
=
\frac{R_k-\overline{R}_c}{Z_c}.
\end{align}
Because all samples in a prompt group share the same $Z_c$ and
$\overline{R}_c$ is their empirical mean, we have
\begin{align}
\frac{1}{K}\sum_{k=1}^{K}\widetilde{A}_k
&=
\frac{1}{KZ_c}
\sum_{k=1}^{K}
(R_k-\overline{R}_c)
\\
&=0.
\label{eq:zero-mean-unclipped-advantage}
\end{align}
Therefore, 
\begin{align}
\delta_r
&=
\mathbb{E}_{c}
\left[
\mathbb{E}_{\mathbf{x}_0\mid c}
\left[
W(\mathbf{x}_0,c)-1
\mid c
\right]
\right]
\\
&=
\mathbb{E}_{c}
\left[
\mathbb{E}_{\mathbf{x}_0\mid c}
\left[
\widehat{A}(\mathbf{x}_0,c)
\mid c
\right]
\right]
=0.
\label{eq:zero-global-delta-linear}
\end{align}

        +
        t_i\boldsymbol{\epsilon}_i$
        for $i=1,\ldots,B$.

        \State $\mathbf{v}_i^{\theta}
        \leftarrow
        \mathbf{v}_{\theta}
        (\mathbf{x}_i^{t_i},c_i,t_i)$.

        \State $\mathbf{v}_i^{\mathrm{old}}
        \leftarrow
        \mathbf{v}_{\theta_{\mathrm{old}}}
        (\mathbf{x}_i^{t_i},c_i,t_i)$.

        \State $\mathbf{v}_i^{\mathrm{ref}}
        \leftarrow
        \mathbf{v}_{\theta_{\mathrm{ref}}}
        (\mathbf{x}_i^{t_i},c_i,t_i)$.

        \State $\widehat{\mathbf{x}}_{0,i}^{\theta}
        \leftarrow
        \mathbf{x}_i^{t_i}
        -
        t_i\mathbf{v}_i^{\theta}$.

        \State $\widehat{\mathbf{x}}_{0,i}^{\mathrm{old}}
        \leftarrow
        \mathbf{x}_i^{t_i}
        -
        t_i\mathbf{v}_i^{\mathrm{old}}$.

        \State $\displaystyle
        \overline{\mathbf{x}}_{0,i}
        \leftarrow
        \widehat{\mathbf{x}}_{0,i}^{\mathrm{old}}
        +
        \frac{
        \beta
        \left(
        W(\mathbf{x}_i^0,c_i)-1
        \right)
        }{
        1+\beta\delta_r
        }
        \left(
        \mathbf{x}_i^0
        -
        \widehat{\mathbf{x}}_{0,i}^{\mathrm{old}}
        \right)$.

        \State $\displaystyle
        \mathcal{L}_{\mathrm{target}}
        \leftarrow
        \frac{A}{B}
        \sum_{i=1}^{B}
        \frac{
        \left\|
        \widehat{\mathbf{x}}_{0,i}^{\theta}
        -
        \overline{\mathbf{x}}_{0,i}
        \right\|_2^2
        }{
        \operatorname{sg}
        \left[
        \operatorname{mean}
        \left|
        \widehat{\mathbf{x}}_{0,i}^{\theta}
        -
        \overline{\mathbf{x}}_{0,i}
        \right|
        \right]
        }$.

        \State $\displaystyle
        \mathcal{L}_{\mathrm{ref}}
        \leftarrow
        \frac{1}{B}
        \sum_{i=1}^{B}
        \left\|
        \mathbf{v}_i^{\theta}
        -
        \mathbf{v}_i^{\mathrm{ref}}
        \right\|_2^2$.

        \State $\mathcal{L}
        \leftarrow
        \frac{1}{N_{acc}}(\mathcal{L}_{\mathrm{target}}
        +
        \lambda_{\mathrm{ref}}
        \mathcal{L}_{\mathrm{ref}})$.

        \State Backpropagate $\mathcal{L}$ and accumulate the gradients
        without updating $\theta$.
    \EndFor

    \State Update $\theta$ once using the accumulated gradients.

    \State $\theta_{\mathrm{old}}
    \leftarrow
    \eta\theta_{\mathrm{old}}
    +(1-\eta)\theta$.
\EndFor
\end{algorithmic}
\end{algorithm}

\section{Experiments}
\label{sec:experiments}

\subsection{Experimental setup}
\label{sec: exp-setting}
We follow the experimental setup used by DiffusionNFT~\citep{zheng2026diffusionnft}. Unless otherwise specified, all experiments start from SD3.5-Medium~\citep{esser2024scaling} at $512 \times 512$ resolution.

\paragraph{Reward models.}
We evaluate both rule-based and model-based reward optimization. The rule-based tasks are GenEval for compositional text-to-image alignment~\citep{ghosh2023geneval} and OCR visual text rendering, using the same prompt splits and partial-credit reward design as the DiffusionNFT and FlowGRPO. The model-based rewards include PickScore~\citep{kirstain2023pickapic}, CLIPScore~\citep{hessel2021clipscore}, HPSv2.1~\citep{wu2023human}, Aesthetic score~\citep{schuhmann2022laion}, ImageReward~\citep{xu2023imagereward}, and UnifiedReward~\citep{wang2025unifiedreward}. Following DiffusionNFT, Pick-a-Pic prompts are used for preference-oriented training~\citep{kirstain2023pickapic}, while DrawBench prompts are reserved for out-of-domain evaluation~\citep{saharia2022photorealistic}.

\paragraph{Training protocol.}
We fine-tune the base model with LoRA~\citep{hu2022lora} using rank $r=32$, scaling factor $\alpha=64$, and learning rate $3 \times 10^{-4}$. Each training epoch contains 48 prompt groups, and each group samples $G=24$ images from the current rollout policy. Rewards are normalized within each group before constructing the optimization weights, so methods are compared under the same reward scale. For single-reward comparisons and ablations, rollouts use 10 sampling steps to match the efficient setting in DiffusionNFT. For multi-reward training and final evaluation, we use 40 sampling steps to reduce sampler-induced quality differences.
